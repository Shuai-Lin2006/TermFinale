# 第 1 轮完成报告：用户排除语义系统（2026-11-13）

## 这轮只做了什么

- 新增 tfv2/product/exclusions.py：自然语言 → 结构化排除（page / section / topic / keyword / question_type / section_limit）。
- 解析 20 条真实说法：页码、章节、考点、题型、只考范围、老师口吻、实验部分、除了 X 都考。
- 匹配资料：按页文本、节标题、章节号定位；输出命中页码、节、占比、是否需要确认。
- 四类输出接入：
  1. 讲义：计划删页、写作 prompt 禁止讲、生成后按块过滤（图注也过滤）。
  2. 提取：prompt 禁止提、条目按考点/名词/题干过滤、排除页从页码范围移除。
  3. 出卷：蓝图过滤题型、页码过滤、题目解析阶段拒收、生成后兜底过滤。
  4. 练习：节/页排除、prompt 禁止、题目过滤。
- 安全：置信度 <0.9、命中超过 30%（且资料≥4页）、只命中标题、歧义（“这个考点”）都不自动删；写 exclusion_report.json；可撤销的 source_quote/matched 留痕。

## 验收结果

- 20 条样例：18 条有明确 scope 全部解析正确；2 条歧义（“这个考点不考”“不考太多”）正确返回 ambiguous，不删内容。准确率 100%（按“能否安全定位”口径）。
- 误删测试：排除“积分中值定理”不会删“定积分计算”；排除“动量守恒”不会删“牛顿第二定律”。
- 测试：418 项全部通过（上一轮 408，本轮新增 10 项排除测试）。
- 真实生成：2 页物理样章，用户说“动量守恒不考”，生成 1 节，正文只剩牛顿第二定律，全文无“动量”；exclusion_report 记录 topic=动量守恒、命中第 2 页；耗时 172 秒。
- 负优化检查：原有 408 项测试全过，PDF/Word/图片/出卷/提取接口未改签名；未改 UI。

## 和之前比，提升在哪（大白话）

之前：
- 只把“明确不考”当关键词，跟资料做字符串包含；
- 用户说“第 3 章不考”可能只匹配标题，正文还在；
- 用户说“积分中值定理不考”分不清是整章“积分”还是这个定理；
- 出卷/提取/练习各自为政，不读同一份排除。

现在：
- 能分清“哪一页、哪一章、哪个考点、哪种题型”；
- 同一个排除规范同时管讲义、提取、出卷、练习；
- 不确定就标出来，不偷偷删；
- 每个排除都有原话、命中页码、可撤销记录。

## 这轮没做（不假装）

- UI 的排除 chip / 确认弹层没做（按路线第 9–12 轮做 UI；本轮只做数据与四类输出）。
- LLM 兜底解析没启用（规则解析已覆盖 20 条；LLM 只作为后续增强）。
- 提取/出卷/练习只做了代码接入和单测，没有各跑一次真实模型全链路；讲义做了真实生成。
- section_limit（只考到第5章）在提取里只做“本节超限报错”，全量提取的跨节范围裁剪还要下一轮补。
