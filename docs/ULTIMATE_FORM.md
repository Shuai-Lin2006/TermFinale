# TermFinale 终极形态（完整版，防止缩水）

> **2026-11-08 锁定：以 `docs/ULTIMATE_FORM_LOCKED.md` 为唯一验收标准。** 本文件保留为完整形态说明；与锁定标准冲突时，以锁定标准为准。实测差距见 `docs/AUDIT_REPORT_2026-11-08.md`。

> 这不是“四个生成按钮”，而是一个本地优先的期末复习工作台。
> 当前进度见 `docs/STATUS_NOW.md`；逐项功能/状态见 `docs/FEATURE_MATRIX.md`；标准见 `SPEC_GUIDE.md`、`SPEC_GENERATION.md`。

## 0. 一句话

把学生的资料变成**能读懂、能练习、能记住、能提分**的复习系统，并让每一步可追溯、可修正；效果必须超过“资料直接丢给顶级 AI + 强提示词”。

## 1. 输入层

- PDF / PPTX / 旧 PPT / DOCX / 图片 / 扫描件；音频为候选。
- 多资料：主资料、辅助资料、权重、页码范围。
- 老师重点：必考、不考、只考、点名页码、禁用词。
- 课程画像：学校/专业/学分、自设难度、自身基础、目标分、剩余天数、人设、权重。
- OCR：扫描页、纯图页、公式页；标“图片识别”，不静默丢页。
- 解析质量：页账本、缺失页、低质文本、公式损坏检测。

## 2. 内容生成层

四类任务，任务级约束独立：

1. **讲义**：精简 / 全量 / 只讲重点；章节目录、考点、概念、推导、例题、易错、小结；图片、公式、页码、覆盖报告。
2. **提取**：考点 / 名词 / 原题；含答案/不含答案；原题号、原题干、不改写、不编答案。
3. **试卷**：原题改数 / 原题变式 / 预测仿真 / 模拟练习 / 参考原卷；卷头、题型、题量、分值、答案与解析；改数/变式标出处；预测不冒真题。
4. **逻辑分析**：主线、概念层级、因果链、考点题型映射、易混对比、学习顺序、页码出处；事实与【推断】分开。

共同要求：只依据资料、可溯源、老师必考覆盖、不考不出现、`validate_output`、违规重试最多 2 次、失败给位置。


### 2.1 讲义标准（2026-11-09 用户锁定，v3 按此验收）

一份合格讲义必须同时满足：

1. **人设与深度**：讲解语气符合用户选的人设；深度/篇幅符合目标分、剩余天数、基础、课程权重；人设只改语气，不改事实/页码/答案。
2. **标头**：题目标题、课程、用户情况（目标分、剩余天数、基础、人设、资料名/覆盖范围）。
3. **教材式结构**：标题下先“本资料讲什么”的全篇摘要（资料涉及哪些内容/主线/考点分布），再目录 + 成稿页码，正文从“第一章/第一节”开始。
4. **正文**：按考点/小节组织；零基础能看懂（直观解释 → 定义/公式 → 跟做例题 → 易错 → 小结）；每小节末尾有资料出处（页码），不能编造。
5. **重点/不考**：用户标了重点，必须在正文/例题/易错/小结中突出；用户明确不考的内容不写。v3 生成表单已加入这两个字段，并在生成后做关键词硬检查（重点未落正文/不考词出现在正文会直接失败）。
6. **覆盖**：单份资料 ≤159 页时全文覆盖；每页至少被一个 block 引用；超过 159 页或超 30 段要求拆分。页数覆盖写入页脚。
7. **图片**：资料里的电路图/模型图/结构图要放在对应讲解段之后，图注+页码；不能拿截图/色块/logo 冒充；自动匹配后仍需人工核对图文对应。
8. **排版**：教材式单栏正文，不堆大卡片；该换行就换行；目录/页码/摘要/正文/出处/结语层级清楚；打印友好。
9. **结语**：正文末尾单独一大段，按人设鼓励；不是模板句。
10. **页脚**：所有 AI 生成资料末尾一行小字：`本资料由 XXX 智能体生成，可涵盖《资料名》约 XX% 的内容；具体请以实际资料为准，本资料不承担由此产生的法律责任。`
11. **可做题**：读完能做题；例题有步骤，练习/错题本能回到对应页。
12. **不冒充**：没有语义审计/人工复核就只标“待复核”，不能因为页数/生成数标“可读”。

v3 当前落地：标头/目录/摘要/小节出处/结语/页脚/图片/重点字段/≤159 页补齐已接；语义审计和人工复核仍未自动完成。


### 2.2 训练模式（AI 出卷）标准（2026-11-10 锁定）

- 可上传历届真题作为参考；四种模式：原题改数、原题变式、模拟、预测；有真题参考时，题型/顺序/格式/分值结构必须仿照真题，不能自由发挥成另一张卷。
- 没有真题时，AI 可按科目自由命题，也允许用户自定义题型、题量、分值；总分必须 100。
- 按科目提供完整题型池：选择、填空、计算、证明、简答、实验、设计、名词解释、病例分析、论述等。
- 难度 1–5 有区分度，但不能全是送分题或全是压轴题；题干必须有背景/条件/推理，不能只有公式套数。
- 物理/电路/几何题需要图时：优先生图；不能生图时必须给出足以作图的详细 figure_description，不能只写“如图”。
- 选择题要有 4 个唯一选项和答案审计；计算/简答答案需人工复核，不能冒充自动判对。
- 试卷支持打印、导出 HTML/Word、直接编辑；页眉含科目/模式/难度/满分/时间/姓名学号得分。
- 当前 v3 已实现结构/100 分/四模式/参考文件/答案三审/打印导出编辑；真题参考和四模式的全量真实样例仍需继续扩测。

### 2.3 提取模式标准（2026-11-10 锁定）

- 至少四种：思维导图、原题提取、考点提取、名词解释。
- 所有条目必须带资料页码；支持“全部资料”而不是只抽一节。
- 选择全部资料时，提取/导图必须覆盖所有页；不能只覆盖前几页。未覆盖 98% 只能标“部分覆盖”，不能冒充全量。
- 原题支持选择/计算/简答；不改写原题、不编答案；真题没答案要明确写“原卷未给答案”。
- 思维导图节点必须有 parent、页码范围，所有节点合起来覆盖全部页码。
- 提取结果支持打印/导出/编辑，末尾带 AI 生成声明。
- 当前 v3：思维导图 31 节点覆盖 85/85 页；混合原题 2 计算 + 1 简答；考点/名词仍可能因模型输出不足标 partial。

### 2.4 三语标准

- 界面必须完整支持简体中文、繁体中文、English；导航、按钮、表单、状态、错误、空态、试卷/任务工具栏都要切。
- 阅读器独立切换也要支持三语，不能只做中/EN。
- 生成内容保持源语言，不机器翻译；课程名、讲义标题、原题正文属于源内容。

## 3. 阅读层

- 目录、章节跳转、全文搜索、结果计数、上一处/下一处。
- 选中文本提问；AI 多轮；回答引用当前页/选中内容；找不到就说未覆盖。
- 笔记：保存问题、回答、页码、课程；可检索、可删除。
- 公式 KaTeX；图片点击放大；图注/页码可查。
- 导出 Word/PDF、打印；HTML + MD 同源。
- 主题：深/浅色；窄窗口；长公式不溢出；空/错/加载态完整。

## 4. 学习闭环层

- 练习：选择/填空/计算/综合；提交判分。
- 错题本：题目、答案、解析、错因、页码、课程。
- 间隔复习：按遗忘曲线安排到期；今日复习队列。
- 掌握度：按知识点/章节统计；薄弱点回到讲义对应页。
- 复习计划：今日目标 → 课程 → 题目 → 进度。
- 资料统计：覆盖页、已生成、未生成、缺失页。
- 目标：不是“生成完”，而是“学完、记住、会做”。

## 5. 约束与个性化层

- 老师重点贯穿所有生成，不是只写在讲义里。
- 难度/基础/目标分影响深度、例题、解释；不改变事实。
- 人设只改语气，不改覆盖/页码/答案；人设写入元数据。
- 三语言按角色处理：界面语言完整切换；生成语言用于讲解/总结/解析；原文、原题、术语、例句保留原语言；翻译单独标“参考译文”。详见 `docs/ULTIMATE_FORM_LOCKED.md` §3。
- 多资料权重影响篇幅和优先级；不伪造来源。
- 任务级约束不共用 `user_note`，避免互相污染。

## 5.1 AI 无处不在层（2026-11-09 锁定）

- 每个页面都有 AI 入口；上下文 = 当前课程/资料/页/选中文本/笔记/错题/生成物。
- 不只是问答：能解释、出题、改这一节、补写章节、排复习、做计划、改笔记；可指定“只做这几页/这个考点”。
- 可自由对话（像豆包），但涉及资料事实必须检索/引用；资料没有就说未覆盖。
- 写操作先预览、可撤销；破坏性操作二次确认；不静默改数据。
- 回答带出处；0 编页码；0 假答案；动作成功/失败可见。
- 技术：`tfv2/agent/`（planner/executor/tools/memory/policy）+ RAG + prompt registry。
- 完整标准见 `docs/ULTIMATE_FORM_LOCKED.md` §2.10。
- v3 已落：全站 AI 抽屉（任意页面可开），上下文=当前资料；可自由对话/解释/出题/7 天计划/提炼重点；消息按资料或通用会话持久化；阅读器另有选中提问。尚未做：AI 直接发起写操作（重写某节/生成讲义）的预览/撤销、工具规划器、社区。

## 6. 质量与评测层

- `validate_output`：结构、排除词、页码、公式、答案、图表、覆盖。
- 覆盖报告：总页数、已引用页、缺失页；单份资料 ≤150 页 ≥98%，>150 页明确概览。
- 图片报告：图源数、使用数、丢弃数、丢弃原因；禁止截图/色块/logo 冒充。
- 答案审计：独立多解、一致/冲突/人工；官方答案错误要标争议。
- 语义复核：自然改写不能只靠 2-gram；需语义/人工抽检。
- 评测集：与“直接问顶级 AI + 强提示词”对比；准确率、覆盖率、可做题率、耗时、成本。
- 错误可发现、可追溯、可修正；不承诺零错误，但不掩盖。

## 7. 体验与 UI 层

- 3 秒知道这页干什么；连续 2 小时不累。
- 每页一个主行动；正文为主，工具折叠，减少过量 AI 推荐。
- 统一设计 token；深/浅色；三语言；长公式；窄窗口。
- 空/错/加载态完整；无死按钮、无错跳、无截断。
- 课程详情：目标/进度 → 资料 → 生成物。
- 阅读页：目录/搜索/选中提问/笔记/导出。
- 复习计划：今日目标 → 课程 → 题目 → 进度。
- 设置：资料、头像、API Key、语言、主题、备份/清理。
- 可访问性：键盘、对比度、字号；不依赖 hover。

## 8. 系统与性能层

- Electron 壳 + FastAPI + SQLite；本地优先，数据不出本机（除模型调用）。
- 任务：进度、取消、断点续跑、错误提示、崩溃恢复。
- 长文档：分块、并发、缓存、页账本、失败重试；1000 页不炸。
- 解析缓存可清；用户资料不可删。
- API Key：DeepSeek 文本；DashScope OCR/视觉；未配置时明确提示。
- 日志/调试产物可诊断，但不泄露密钥。
- 数据备份/恢复；测试数据隔离。

## 9. 发布与商业层

- Mac 安装包、签名/公证；Windows 安装包/实体机验证。
- 官网：介绍、截图、下载、更新日志。
- GitHub：开源（倾向 AGPL-3.0）、Issue、文档。
- 10 人内测；成本上限；其他人自带 API Key。
- 用户反馈渠道；崩溃/隐私说明。
- 发布门禁：内容、UI、数据、答案、安装包全过才叫发布。
- 社区/移动端是候选，不是当前 P0；不因此稀释桌面核心。

## 10. 北极星指标

- 内容：覆盖率、缺失页、公式错误、图片错配、答案正确率。
- 学习：做完题的正确率、错题复习完成率、掌握度提升。
- 体验：任务完成率、取消/恢复成功率、崩溃率、导出成功率。
- 对比：同一资料 vs 直接问顶级 AI，谁更完整、更可追溯、更能做题。
- 信任：用户能指出“这页来源哪、这题为什么对/错”。

## 11. 明确不做/不承诺

- 不替代老师/教材/课堂。
- 不承诺零错误；承诺错误可发现、可追溯、可修正。
- 不把概览说成逐页精准。
- 不把测试数据混入正式输出。
- 不为篇幅删老师必考点。
- 不用“任务成功”代替“内容通过”。
