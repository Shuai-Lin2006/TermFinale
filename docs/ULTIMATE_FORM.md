# TermFinale 终极形态（完整版，防止缩水）

> 这不是“四个生成按钮”，而是一个本地优先的期末复习工作台。
> 当前进度见 `docs/STATUS_NOW.md`；逐项功能/状态见 `docs/FEATURE_MATRIX.md`；标准见 `SPEC_GUIDE.md`、`SPEC_GENERATION.md`。

## 0. 一句话

把学生的资料变成**能读懂、能练习、能记住、能提分**的复习系统，并让每一步可追溯、可修正；效果必须超过“资料直接丢给顶级 AI + 强提示词”。

## 1. 输入层

- PDF / PPTX / 旧 PPT / DOCX / 图片 / 扫描件；音频为候选。
- 多资料：主资料、辅助资料、权重、页码范围。
- 老师重点：必考、不考、只考、点名页码、禁用词。
- 课程画像：学校/专业/学分、自设难度、自身基础、目标分、剩余天数、人设、权重。
- OCR：扫描页、纯图页、公式页；标“图片识别”，不静默丢页。
- 解析质量：页账本、缺失页、低质文本、公式损坏检测。

## 2. 内容生成层

四类任务，任务级约束独立：

1. **讲义**：精简 / 全量 / 只讲重点；章节目录、考点、概念、推导、例题、易错、小结；图片、公式、页码、覆盖报告。
2. **提取**：考点 / 名词 / 原题；含答案/不含答案；原题号、原题干、不改写、不编答案。
3. **试卷**：原题改数 / 原题变式 / 预测仿真 / 模拟练习 / 参考原卷；卷头、题型、题量、分值、答案与解析；改数/变式标出处；预测不冒真题。
4. **逻辑分析**：主线、概念层级、因果链、考点题型映射、易混对比、学习顺序、页码出处；事实与【推断】分开。

共同要求：只依据资料、可溯源、老师必考覆盖、不考不出现、`validate_output`、违规重试最多 2 次、失败给位置。

## 3. 阅读层

- 目录、章节跳转、全文搜索、结果计数、上一处/下一处。
- 选中文本提问；AI 多轮；回答引用当前页/选中内容；找不到就说未覆盖。
- 笔记：保存问题、回答、页码、课程；可检索、可删除。
- 公式 KaTeX；图片点击放大；图注/页码可查。
- 导出 Word/PDF、打印；HTML + MD 同源。
- 主题：深/浅色；窄窗口；长公式不溢出；空/错/加载态完整。

## 4. 学习闭环层

- 练习：选择/填空/计算/综合；提交判分。
- 错题本：题目、答案、解析、错因、页码、课程。
- 间隔复习：按遗忘曲线安排到期；今日复习队列。
- 掌握度：按知识点/章节统计；薄弱点回到讲义对应页。
- 复习计划：今日目标 → 课程 → 题目 → 进度。
- 资料统计：覆盖页、已生成、未生成、缺失页。
- 目标：不是“生成完”，而是“学完、记住、会做”。

## 5. 约束与个性化层

- 老师重点贯穿所有生成，不是只写在讲义里。
- 难度/基础/目标分影响深度、例题、解释；不改变事实。
- 人设只改语气，不改覆盖/页码/答案；人设写入元数据。
- 三语言：简体/繁體/English；全文一致，不中英混排。
- 多资料权重影响篇幅和优先级；不伪造来源。
- 任务级约束不共用 `user_note`，避免互相污染。

## 6. 质量与评测层

- `validate_output`：结构、排除词、页码、公式、答案、图表、覆盖。
- 覆盖报告：总页数、已引用页、缺失页；≤150 页 ≥98%，>150 页明确概览。
- 图片报告：图源数、使用数、丢弃数、丢弃原因；禁止截图/色块/logo 冒充。
- 答案审计：独立多解、一致/冲突/人工；官方答案错误要标争议。
- 语义复核：自然改写不能只靠 2-gram；需语义/人工抽检。
- 评测集：与“直接问顶级 AI + 强提示词”对比；准确率、覆盖率、可做题率、耗时、成本。
- 错误可发现、可追溯、可修正；不承诺零错误，但不掩盖。

## 7. 体验与 UI 层

- 3 秒知道这页干什么；连续 2 小时不累。
- 每页一个主行动；正文为主，工具折叠，减少过量 AI 推荐。
- 统一设计 token；深/浅色；三语言；长公式；窄窗口。
- 空/错/加载态完整；无死按钮、无错跳、无截断。
- 课程详情：目标/进度 → 资料 → 生成物。
- 阅读页：目录/搜索/选中提问/笔记/导出。
- 复习计划：今日目标 → 课程 → 题目 → 进度。
- 设置：资料、头像、API Key、语言、主题、备份/清理。
- 可访问性：键盘、对比度、字号；不依赖 hover。

## 8. 系统与性能层

- Electron 壳 + FastAPI + SQLite；本地优先，数据不出本机（除模型调用）。
- 任务：进度、取消、断点续跑、错误提示、崩溃恢复。
- 长文档：分块、并发、缓存、页账本、失败重试；1000 页不炸。
- 解析缓存可清；用户资料不可删。
- API Key：DeepSeek 文本；DashScope OCR/视觉；未配置时明确提示。
- 日志/调试产物可诊断，但不泄露密钥。
- 数据备份/恢复；测试数据隔离。

## 9. 发布与商业层

- Mac 安装包、签名/公证；Windows 安装包/实体机验证。
- 官网：介绍、截图、下载、更新日志。
- GitHub：开源（倾向 AGPL-3.0）、Issue、文档。
- 10 人内测；成本上限；其他人自带 API Key。
- 用户反馈渠道；崩溃/隐私说明。
- 发布门禁：内容、UI、数据、答案、安装包全过才叫发布。
- 社区/移动端是候选，不是当前 P0；不因此稀释桌面核心。

## 10. 北极星指标

- 内容：覆盖率、缺失页、公式错误、图片错配、答案正确率。
- 学习：做完题的正确率、错题复习完成率、掌握度提升。
- 体验：任务完成率、取消/恢复成功率、崩溃率、导出成功率。
- 对比：同一资料 vs 直接问顶级 AI，谁更完整、更可追溯、更能做题。
- 信任：用户能指出“这页来源哪、这题为什么对/错”。

## 11. 明确不做/不承诺

- 不替代老师/教材/课堂。
- 不承诺零错误；承诺错误可发现、可追溯、可修正。
- 不把概览说成逐页精准。
- 不把测试数据混入正式输出。
- 不为篇幅删老师必考点。
- 不用“任务成功”代替“内容通过”。
