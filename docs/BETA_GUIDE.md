# 内测指南（10 人小范围）

> 谢谢帮忙测试 🙏 这是个还没正式发布的版本，有问题很正常，你的反馈会直接决定它后面怎么改。
> 测试期由我承担 API 费用，你不需要自己充值。

## 一、安装（macOS）

1. 解压我发给你的 `TermFinale.app.zip`
2. 把 `TermFinale.app` 拖进「应用程序」
3. **首次打开会被系统拦一下**（因为没做 Apple 公证）：
   - 在「应用程序」里**右键**点击 App → 选择「打开」→ 再点「打开」
   - 或者终端执行一次：`xattr -dr com.apple.quarantine /Applications/TermFinale.app`
4. 之后双击就能正常打开

> 仅支持 Apple Silicon（M1/M2/M3/M4）。Intel Mac 暂时跑不了。

## 二、配置 Key（我会单独发给你）

1. 打开软件 → 右上角 **⚙ 设置**
2. 把 **DeepSeek Key** 粘进第一个框（必填）
3. 「测试连接」看到 `DeepSeek ✅` 后点「保存」
4. 百炼 Key 可以不填，只影响图片有没有文字说明

⚠️ 这个 Key 是我出的测试额度，**请不要转发给任何人**，也不要截图发到公开平台。

## 三、请重点试这三件事

### 1. 生成一份讲义
新建科目 → 上传你手头任意一门课的 PDF/PPT（**建议先用 10~30 页的**）→ 选「精简讲义」→ 生成。

看这几点：
- 章节编号是不是 1、2、3 连续
- 图片有没有出来、有没有被截断
- 讲义里的"必背/公式卡/例题"读起来顺不顺
- 有没有明显编造的内容（对照原资料）

### 2. 复习模式
课程卡片 → 「复习模式」：
- **资料提取 → 考点**：看每个考点是否讲清楚（是什么/怎么考/怎么答/易错点）
- **训练试卷**：生成一套，看看题目像不像大学期末题、有没有答案和解析
- **逻辑分析**：图谱和因果链是不是能看懂

### 3. 边角情况
- 上传一个**很大的 PDF**（比如 100 页），看会不会卡住、进度有没有在动
- 生成过程中点「停止生成」，看会不会正常退出
- 关掉软件再打开，看你填的名字和 Key 还在不在

## 四、怎么反馈

按这个格式发我就行，越具体越好：

```
系统：macOS 14 / M2
操作：新建课程 → 上传 xxx.pdf（32 页）→ 精简讲义
现象：第 3 章生成到一半停了，进度条卡在 60%
截图：（附一张）
日志：~/Library/Application Support/TermFinale/logs/ 里最新那个文件
```

**日志位置**（出问题时把最新的 `.log` 发我）：

| 系统 | 路径 |
|---|---|
| macOS | `~/Library/Application Support/TermFinale/logs/` |
| Windows | `%APPDATA%\TermFinale\logs\` |

如果软件崩溃打不开，同一个目录下会有 `crash.log`。

## 五、已知问题（不用重复报）

- 第一次生成慢（要逐张识别图片），第二次同一份资料会快很多
- 没有做 Apple 公证，所以首次打开要右键
- 深色模式还没做
- 复习页面的按钮/卡片还在打磨中
- 英文模式下部分文案仍是中文

## 六、卸载 / 清空数据

- 删掉 `/Applications/TermFinale.app`
- 数据目录：`~/Library/Application Support/TermFinale/`（删除即彻底清空）
