# 最终形态执行计划（一步一步）

> 原则：先底层可信，再体验；每个阶段有硬门禁，未过不进入下一阶段。

## 阶段 0：基线与门禁（进行中）
- 127+ 测试、页账本、覆盖率（≤150=100%、150–1000≥85%、>1000≥60%）。
- 当前：85 100%、171 98.8%、1001 77.2%；130 测试。
- 出口：release_gate 覆盖类全过；已有。

## 阶段 1：课程级 AI + 证据链（P0，当前）
1. `core/retrieval.py` 页索引/检索；测试。
2. `/api/ask` 改为课程级 RAG：question + selection + top pages；返回 sources；无依据拒答。
3. 全局 AI 抽屉（所有页面）；历史/存笔记。
4. 逐句证据门禁从 5.2% 拉到 ≥80%，再 ≥95%。
5. 生成后“证据面板”：每段可点开来源页。
- 出口：任意页面能问课程内容；回答带 P.N；无依据明说；证据率 ≥80%。

## 阶段 2：意图 + 权重（P0）
- Study Contract：规则+模型抽取+确认；50–100 条未见口语回归。
- 权重真实预算：资料/章节/例题/篇幅；人设/目标/基础影响难度但不极端。
- 出口：同一资料不同权重产出可观察差异；契约可编辑。

## 阶段 3：题目/图文质量（P0）
- 题干背景/条件/数据；缺图描述；资料原图/配对审计 ≥99%。
- 答案双解；语义/数值能验算的验算，不能验算标注。
- 出口：真实文件矩阵逐题验收。

## 阶段 4：学习闭环 + UI 大重构（P1）
- 诊断→掌握度→今日 5 题→错题→间隔复习→再测。
- 三语言/黑白/5 主题色；阅读层级、搜索、空/错状态、性能。
- 出口：真实用户可用性测试；无死按钮/无卡顿。

## 阶段 5：评估 + 发布（P2）
- 同资料 vs 顶级模型+强提示词，用户盲评。
- 网页/GitHub/Windows/签名；最后做。
- 出口：盲评不输；安装包可运行。

## 现在做什么
- 先做阶段 1 的检索与课程级问答；不再先改 UI。

## 候选阶段（用户确认后再排期）
- 社区：只读精选库/用户自有内容优先；开放上传需审核与版权方案。
- 移动端：PWA + 二维码连电脑优先；原生/云同步后置。
- 当前不排期、不实现，避免摊大饼。
