# 具体操作步骤

## A. 发放方：创建和发放

### 1. 创建 Key

以 DeepSeek 为例（百炼同理，按需创建）：

1. 登录服务商控制台 → API Keys
2. 每人创建一个，命名清楚：`tf-beta-01-昵称`
3. 创建后**只显示一次**，立刻复制到密码管理器/加密备忘录
4. 不要用同一个 Key 发给两个人
5. 如果控制台支持额度/预算/告警，先设上限；不支持就每天人工看用量

百炼 Key 只在用户要测**图片型 PDF/PPT** 时才需要；文字版资料不需要。

### 2. 登记

在登记表只记：昵称、发放日期、Key 尾号（后 4 位）、状态。
**不要记完整 Key，不要截图控制台。**

### 3. 私聊发放

一人一条私聊，发三样东西：

1. 下载页：https://shuai-lin2006.github.io/TermFinale/
2. 他的 Key（单独一行，方便复制）
3. 下面这段使用说明

> 这是你的 TermFinale 内测 Key，只给你一个人，请勿转发。
> 安装后打开：设置 → 模型 → 粘贴到「DeepSeek Key」→ 点「测试连接」。
> 如果要测图片型 PDF/PPT，再填「阿里云百炼 API KEY」。
> Key 有额度，图片资料消耗更快；失效或换电脑在 QQ 群 1134219836 找我。

### 4. 分批放量

- 第 1 天：先发 1–2 人，确认能装、能填、能生成
- 第 2 天：再发 3–4 人
- 第 3 天：剩余的人
- 任何一人出现 401/402/429 或异常用量，先暂停发放

## B. 用户：安装和填写

### 1. 安装

- Windows：双击 `TermFinale-0.6.2-win-x64-setup.exe` → Next → Install；SmartScreen 选「更多信息 → 仍要运行」
- Mac（M 系列）：打开 dmg → 拖进「应用程序」→ 首次右键「打开」

### 2. 填 Key

1. 打开 TermFinale
2. 左侧点「设置」→「模型」
3. 在「DeepSeek Key」粘贴 Key
4. 需要图片资料时，再填「阿里云百炼 API KEY」
5. 点「测试连接」，看到 DeepSeek / 百炼状态变绿
6. 返回「课程库」

### 3. 跑一份资料

1. 新建课程
2. 上传 PDF / PPTX / DOCX
3. 勾选要讲的页（先选 2–4 页试）
4. 选档位、人设，点预览
5. 预览没问题 → 同意继续生成完整讲义
6. 生成完自动进阅读页；右上角可导出

## C. 出问题怎么排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 测试连接失败 / 401 | Key 复制不全、已删除、填错栏 | 重新复制；确认填在 DeepSeek 栏 |
| 402 / 余额不足 | 额度用完 | 停用该 Key，登记，联系发放方 |
| 429 / 请求过多 | 多人共用一个 Key 或短时间狂点 | 一人一 Key；等几分钟再试 |
| 一直转圈/超时 | 网络或模型排队 | 换网络；减少页数；看任务是否失败 |
| 图片 PDF 不能生成 | 没填百炼 Key | 设置 → 模型 → 填百炼 Key |
| Mac 打不开 | Gatekeeper | 右键「打开」，或系统设置 → 隐私与安全性 → 仍要打开 |
| Windows 报毒/SmartScreen | 无代码签名 | 「更多信息 → 仍要运行」 |

## D. 停用和轮换

1. 内测结束：控制台把 10 个 Key 全部禁用/删除
2. 某人退出：只停他的 Key，不影响其他人
3. Key 泄露：立即吊销 → 群里说明 → 必要时补发一个新 Key
4. 换电脑：旧 Key 可继续用，但不要两台同时跑；建议先停旧再发新
5. 每月核对一次：控制台 Key 列表 vs 登记表，删掉不用的
