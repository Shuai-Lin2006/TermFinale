# 逐事实生成试验（2026-11-15）

## 结果

- 10 页、5 节、7 图；
- 每条页面事实单独生成 2–3 句解释；
- 50 条事实，31.9s 生成；
- 第一次 audit：2 covered / 5 partial / 3 overview；
- 补缺失点后：5 covered / 2 partial / 3 overview；
- 再补最后 2 页后：4 covered / 2 partial / 1 missing / 3 overview。

## 结论

- 逐事实生成能短期提升，但 **audit 本身在波动**；
- 同一份内容，补两页后 covered 从 5 掉到 4；
- 继续“补完再审计”不会收敛；
- 评分仍约 **48%**，距第一梯队 **52%**。

## 根因

- audit 是模型判断，不是确定性映射；
- 需要本地“事实 → block”覆盖表，先确定性检查，再让模型只判断深度；
- 否则每次审计都在换标准。

## 停止

- 不再补事实块；
- 不再跑 50/100 页；
- 不再用 audit 波动当进度。

## 下一步

1. 每条事实必须绑定一个 block id；
2. 本地检查覆盖率（确定性）；
3. 只对“有 block 但深度不足”的事实做局部重写；
4. 2 页组确定性覆盖 100% 后，再跑模型 audit。
