# 重构第 1 轮（修订）：撤回可见噪音，只保留底层修复

## 用户反馈

用户明确指出：“今天到期 / 出一套题”卡片莫名其妙；“证据审计 / 弱引用 / 页级 / 错位”这些术语用户看不懂也不会在意。这个判断是对的。第 1 轮把内部质量指标当成了用户价值，属于负优化。

## 已撤回

- 首页 4 张任务卡（继续上次 / 今日到期 / 下一门课 / 今日一练）全部删除，首页恢复原来的轨道布局。
- 质量报告页的“证据审计”卡删除；不再向用户展示“弱引用 / 页级 / 错位 / 验证 60/64”这些内部术语。
- 通用页图保底默认关闭：只有设置环境变量 TFV2_FIGURE_FALLBACK=1 才会挂“资料第 X 页图示”这类保底图；不再把页面截图当“图文并茂”。
- 测试课程（高等数学 / 生物 / OCR测试 / 生物重构）已从课程库删除；测试练习的 3 道题、attempt、mistake 已清理。原有解剖学 / 护理 / 有机化学 / 高数课程未动。
- 静态资源版本号保留，避免用户继续加载旧 JS。

## 保留的底层修复（不影响界面）

### 1. 源与生成物分离

- 新增 tfv2/product/source_pages.py：原始 PDF/PPTX 的逐页文本/图片缓存为 source_pages.json。
- 提取、出卷、练习改为优先读原始页，不再把生成后的 sections.json 当唯一事实源。
- 生成时保存 source_pages.json；source-only 保存时也保存。
- tests/test_source_pages.py 覆盖缓存读写。

### 2. 防止假通过（只在结果层判断，不展示术语）

- 新增 tfv2/quality/trust.py：
  - 证据 quote 必须是引用页逐字子串，且与 block 文本有重叠；
  - 逻辑分析页覆盖 < 98% 不通过；
  - 试卷题数/分值/总分、页覆盖、近重复、解析自我纠错、答案/解析数值不一致、选择题审计冲突，任一命中不通过。
- 旧的已保存试卷/分析在读取时重新审计，旧的“通过”会变成“未通过”；不把错误内容继续标成通过。
- 但 UI 不再展示这些审计细节；用户只看到结果状态。

### 3. 搜索排序

- /api/search 全库合并分数、低分丢弃、按分数降序。
- 实测“交感”：解剖学“交感与副交感…”从第 4 位升到第 1 位。

### 4. 阅读器去重

- iframe 加 embed=1；内层搜索/编辑/导出隐藏，父层已有同名控件。旧讲义由父层 CSS 隐藏。

## 验证

- tests.test_source_pages：1/1
- tests.test_tfv2_product + trust：26/26
- 更广 tfv2 测试：53 项通过
- 源 app 8917：搜索第一命中正确；旧 variant 卷 rejected；旧全部资料分析 rejected；首页恢复原轨道、无横向溢出/控制台错误。

## 下一步（不再做 dashboard / 审计界面）

1. 讲义内容：提高深度/篇幅/例题/小结，先把“能读懂、能做题”做出来。
2. 图片：DocLayout/MinerU 裁剪 + VLM 图注 + 图文相关性；不再用整页截图凑数。
3. 模型：切 deepseek-v4-pro + reasoning high，按任务路由，16k-32k 输出；用 A/B 证明比 flash 好。
4. 真题变式：真题题级解析 + “真题第 X 题 → 变式第 Y 题”映射 + 答案验证。
5. 数学答案：SymPy 验证；不靠模型自审。
6. 练习/复习：全题型 + FSRS/IRT；不展示“审计”术语。
7. UI：保持现在克制的教材感；不再加卡片/术语；出卷只保留蓝图和真题结构。
