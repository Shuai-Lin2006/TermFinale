# TermFinale 终极形态·锁定标准（2026-11-08）

> **状态：LOCKED。**
> 这份文件是 TermFinale 的产品/内容/质量/发布验收标准。以后所有功能、生成物、UI、评测、发布都向它看齐。
>
> 它与旧文档冲突时，**以本文件为准**，特别是旧版本中的：
> - “三语言全文一致、不得中英混排”（已在 2026-11-08 修正为 §3 的四角色模型）；
> - 任何“任务成功=内容通过”“生成数=进度”“资料存在=覆盖”的旧口径。
>
> 实测差距见 `docs/AUDIT_REPORT_2026-11-08.md`；重构路径见 `docs/REFACTOR_PLAN_2026-11-08.md`。

---

## 0. 一句话

**把学生的资料变成能读懂、能练习、能记住、能提分的复习系统，并让每一步可追溯、可修正；效果必须超过“资料直接丢给顶级 AI + 强提示词”。**

不是“四个生成按钮”。完整形态必须同时包含：

**输入 → 四类生成 → 阅读器 → 学习闭环 → 约束/个性化 → 质量/评测 → UI/体验 → 系统/性能 → 发布。**

---

## 1. 最高优先级

1. **学生读得懂、记得住、能做课后题。**
2. **每一章、每一题、每一条考点都能回到资料页。**
3. **老师必考必须覆盖；老师不考命中即失败。**
4. **答案必须独立审计；错答案 0 才交付。**
5. **不把“任务成功”“生成数”“测试数”当成内容质量。**
6. **不承诺零错误；错误必须可发现、可追溯、可修正。**

---

## 2. 九层标准

### 2.1 输入层

- 支持 PDF / PPTX / 旧 PPT / DOCX / 图片 / 扫描件；音频为候选。
- 多资料、权重、页码范围；老师必考/不考/只考/点名页码/禁用词；课程画像（学校/专业/学分、难度、基础、目标分、剩余天数、人设）。
- 页账本：每页文本/图片/OCR/质量/缺失原因；不得静默丢页。
- OCR 页标“图片识别”；公式损坏/低质文本要浮出来。
- 解析缓存按内容 hash；测试数据 namespace。
- **合格线**：每一页都有账；读不出来的页要显示；用户知道哪些页不可用。

### 2.2 内容生成层

四类任务，任务级约束独立，不共用 `user_note`。

#### 讲义（2026-11-09 用户锁定）

**结构（固定顺序）**

1. **标头**：讲义标题 + 课程/资料 + 用户情况（目标分、剩余天数、基础、资料数、覆盖范围、生成时间）。**人设只用于生成语气，不写入标头/讲义**；不放 App 名、开发者、随机祝福、源文件名。
2. **教材式目录**：章节/小节 + 页码；目录后分页；不得截断。
3. **全篇摘要**：这份资料涉及什么（知识地图、章节分布、考点权重、怎么用）；1–2 页。
4. **正文**：按章节/考点；零基础可读；每节按“考点 → 概念/公式 → 推导 → 例题 → 易错 → 小结”组织；自然成文，不机械贴标签。
5. **每小节末尾**：一行小字“出处：第 X–Y 页”；正文不出现 P.x；章末汇总。
6. **图片**：放在对应讲解下方；图注 + 来源页；精准匹配；电路图/模型图清晰；禁止 PPT 截图/色块/logo 冒充。
7. **结语**：单独一大段，按人设鼓励；不模板化。
8. **页脚**：一行小字“本资料由 TermFinale 智能体生成，覆盖《资料名》约 xx%；具体以实际资料为准，不承担由此产生的法律责任。”文案可配置，发布前法务确认。

**排版**

- 教材式：段落间距、首行缩进、清晰标题层级、页边距、打印页码；不要大卡片/大色块/装饰性容器。
- 长公式独立成行；图注小字；表格用于对比/数据。
- 目录/正文/页脚在 Word/PDF/打印中保持稳定。

**覆盖与重点**

- 单份资料 ≤150 页，且用户没有额外老师重点：逐页全覆盖，覆盖 ≥98%，缺失页逐页列出。
- 用户给了必考/只考/不考：优先老师约束；必考 100% 覆盖，不考 0 命中；不要求为“全覆盖”写不考内容。
- 单份资料 >150 页：章节概览，明确不承诺逐页；不得冒充逐页。
- “150 页”指单个资料，不是多份资料相加。
- 用户说“几乎全篇都是重点”时，默认按全量处理；可以内部设重点做测试，但不得伪造“老师说”。

**人设与深度**

- 语气符合人设；深度符合目标分/基础/难度/权重；人设不改事实、覆盖、页码、答案。
- 零基础：先补前置，再给例子/步骤；基础好：直接结论 + 综合题 + 易错辨析。

**合格线**

- 学生读得懂、记得住、能做课后题；不是卡片拼接/模板句/PPT 转文字。
- 每小节有出处；图片与讲解对应；目录/摘要/结语/页脚齐全。
- 0 空章、0 重复章、0 只有标题、0 裸 LaTeX、0 编造页码/定理/题目/答案。

#### 提取

- `points` / `nouns` / `questions` 三套独立 schema。
- 每条必须有出处页码；原题逐字、原题号、选项、答案/解析；没答案写“原卷未给答案”。
- 含答案/不含答案两种模式；不含答案不泄题。
- **合格线**：0 条无出处、0 条改写、0 条编答案；覆盖 ≥98%（单份资料 ≤150 页）。

#### 试卷

- 五种模式：原题改数 / 原题变式 / 预测仿真 / 模拟练习 / 参考原卷。
- 改数/变式必须“改编自第 X 页第 Y 题”，并重算答案。
- 预测/模拟/参考卷不得冒真题、不得写原资料页码。
- 答案完整、重复题 0、空题 0；答案必须在选项内；选项唯一。
- **答案审计**：独立求解/数值校验/量纲/边界；冲突标争议，不交付。
- **合格线**：错答案 0；题目可做；不是“看起来像卷子”。

#### 逻辑分析

- 一句话主线、概念层级、因果/推导链、考点题型映射、易混对比、学习顺序、页码出处。
- 事实与【推断】分开；不写空泛鸡汤；每条建议可执行。
- **合格线**：3 句话能复述主线；因果链可回溯；空结果硬失败。

#### 共同

- 只依据资料；重要结论带页码；资料没有标“资料未覆盖/【延伸】”；不得编页码、定理、题目、答案。
- 所有 AI 生成物（讲义/提取/试卷/分析/练习）末尾统一一行小字页脚：智能体名称、覆盖资料/百分比、以实际资料为准、免责声明；不影响阅读。
- `validate_output`；违规重试最多 2 次；仍失败列位置判失败。
- **任务级约束独立**；不共用 `user_note`。

### 2.3 阅读层

- 目录/章节跳转、全文搜索、结果计数、上一处/下一处。
- 选中提问、AI 多轮、回答引用当前页/选中内容；找不到说未覆盖。
- 笔记保存/检索/删除；带课程/章节/页码。
- 公式 KaTeX；图片放大；图注页码。
- Word/PDF/打印；HTML + MD 同源。
- 深/浅色；窄窗口；长公式不溢出；空/错/加载态完整。
- **合格线**：3 秒知道这页干什么；连续 2 小时不累；无死按钮/错跳/截断。

**标头**：标题 + 用户情况（目标/天数/基础/资料数/覆盖）；不得出现人设标签、App 名、开发者、源文件名、随机祝福。

### 2.4 学习闭环层

- 练习：选择/填空/计算/综合；提交判分。
- 错题本：题目、答案、解析、错因、页码、课程。
- 间隔复习：遗忘曲线、今日队列。
- 掌握度：按知识点/章节；薄弱点回到讲义对应页。
- 复习计划：今日目标 → 课程 → 题目 → 进度；真实完成数，不是 0/0=100%。
- 资料统计：覆盖页、已生成、未生成、缺失页。
- **合格线**：不是“生成完”，是“学完、记住、会做”。

### 2.5 约束与个性化层

- 老师重点贯穿所有生成。
- 难度/基础/目标分影响深度、例题、解释，不改变事实。
- 人设只改语气，不改覆盖/页码/答案；人设信息不写入讲义。
- 多资料权重影响篇幅/优先级，不伪造来源。
- 任务级约束独立。
- **合格线**：为这个学生、这门课、这个老师；不是通用 AI 笔记。

### 2.6 质量与评测层

- `validate_output`：结构、排除词、页码、公式、答案、图表、覆盖。
- 覆盖报告：总页数、已引用页、缺失页；单份资料 ≤150 页 ≥98%；>150 页概览。
- 图片报告：图源数、使用数、丢弃数、丢弃原因；禁止 PPT 截图/色块/logo 冒充。
- 答案审计：独立多解、一致/冲突/人工；官方答案错误标争议。
- 语义复核：自然改写不能只用 2-gram；需语义/人工抽检。
- 评测集：与“直接问顶级 AI + 强提示词”对比；准确率、覆盖率、可做题率、耗时、成本。
- 发布后盲测；不承诺零错误。
- **合格线**：用户能指出“这页来源哪、这题为什么对/错、这张图为什么丢、这次为什么失败”。

### 2.7 UI/体验层

- 3 秒知道这页干什么；连续 2 小时不累。
- 每页一个主行动；正文为主，工具折叠。
- 统一设计 token；深/浅色；三语言；长公式；窄窗口。
- 空/错/加载态完整；无死按钮、无错跳、无截断。
- 课程详情：目标/进度 → 资料 → 生成物。
- 阅读页：目录/搜索/选中提问/笔记/导出。
- 复习计划：今日目标 → 课程 → 题目 → 进度。
- 设置：资料、头像、API Key、语言、主题、备份/恢复。
- 可访问性：键盘、对比度、字号、不依赖 hover。
- **合格线**：像学习工具，不像 AI 功能演示。

### 2.8 系统/性能层

- Electron + FastAPI + SQLite；本地优先。
- 任务进度、取消、断点续跑、崩溃恢复。
- 长文档分块、并发、缓存、页账本、失败重试；1000 页不炸。
- 解析缓存可清；用户资料不可删。
- API Key 明确提示；日志不泄露密钥。
- 备份/恢复；测试隔离。
- 输出命名不覆盖；统一到 outputs；缺失文件显示“需重生成”。
- **合格线**：中断能续、崩溃能恢复、长任务不炸、用户数据不丢。

### 2.9 发布/商业层

- Mac 安装包、签名/公证；Windows 安装包/实体机。
- 官网；GitHub（AGPL-3.0 倾向）。
- 10 人内测；成本上限；其他人自带 Key。
- 反馈渠道；崩溃/隐私说明。
- 发布门禁：内容、UI、数据、答案、安装包全过。
- 社区/移动端是候选，不是当前 P0。
- **合格线**：没有发布，不能盲测顶级 AI，也不能说“超过”。

### 2.10 AI 无处不在层（横向层，2026-11-09 锁定）

> AI 不是“一站式生成完就丢给用户”，而是贯穿输入、阅读、练习、复习、设置、导出的随身助教。

- **入口**：每个页面都有 AI 入口；上下文 = 当前课程/资料/页/选中文本/笔记/错题/生成物。
- **能力**：
  - 问答/解释/举例/总结/翻译（按语言角色）；
  - 生成/改写/补写：讲义章节、提取、试卷、分析；可指定“只做这一节/这几页/这个考点”；
  - 学习行动：出题、判分、错题、复习计划、掌握度诊断；
  - 自由对话：像豆包一样任意聊；涉及资料事实必须检索/引用；资料没有就说未覆盖。
- **不是一次性生成**：多轮、记忆、工具调用、预览/撤销、权限确认。
- **工具**：检索、解析、生成、校验、编辑笔记、建练习、排复习、导出；写操作先预览，破坏性操作二次确认。
- **质量**：回答带出处；0 编页码；0 假答案；动作成功/失败可见；延迟/成本可观测。
- **架构**：`tfv2/agent/`（planner/executor/tools/memory/policy）；prompt registry；RAG；结构化 action。
- **合格线**：用户在任何页面都能“问、改、练、排”，且 AI 的行为可追溯、可撤销、可验证。

## 3. 语言标准（四角色）

> 这是对旧“全文一致、不得中英混排”的**替换**。

| 角色 | 管什么 | 规则 |
|---|---|---|
| UI 语言 | 按钮、菜单、标题、空/错/加载、提示、对话框 | 切换后完整、干净；不并列双语；不半翻译 |
| 生成语言 | 讲义正文、过渡、总结、易错、答案解析、分析说明 | 按用户选择；角色内一致 |
| 源内容语言 | 原文引用、原题、术语、例句、标题、代码、公式 | 保留原语言；不擅自翻译/改写 |
| 译文 | 需要时的翻译 | 单独标“参考译文”；不覆盖原文；原题译文不进题干 |

**示例**

- 英语课资料 + 中文生成：原文/原题/术语英文；讲解中文；术语首次 `source term（中文）`。
- 中文资料 + 英文生成：原文/原题中文；讲解英文；术语保留中文，可加英文注释。
- 繁體原文 + 简体生成：原文繁體；讲解简体；转写标明。
- 试卷：题干语言跟课程/原题；解析跟生成语言；整卷换语言用独立“试卷语言”设置。

**校验**：不再把“混排”本身当违规；检查 UI 混排、生成语言不一致、原文被翻译/改写、原题被改动、译文未标、术语被替换、含答案泄题。

## 4. 硬门禁（P0，不过即失败）

1. **覆盖**：单份资料 ≤150 页 ≥98%，缺失页逐页列出；>150 页概览，不冒充逐页。
2. **出处**：重要结论 100% 页码；原题 100% 原样；无编页码/定理/题目/答案。
3. **老师**：必考 100% 覆盖；不考 0 命中。
4. **答案**：独立审计；错答案 0；选项唯一；答案在选项内；量纲/边界通过。
5. **结构**：0 空章、0 重复章、0 只有标题；0 重复题、0 空题、0 无答案。
6. **图片**：0 PPT 截图/色块/logo 冒充；图源/使用/丢弃报告完整；结构图清晰。
7. **语言**：UI 0 混排；源内容 0 擅自翻译；译文 100% 标记；生成语言一致。
8. **公式**：0 裸 LaTeX；0 渲染错误。
9. **系统**：任务可取消/可恢复；输出不覆盖；用户资料不丢。
10. **发布**：签名/公证/Windows/官网/内测/盲测全过。

**任何一条不过，任务状态不能是“完成”，UI 不能显示绿色“已完成”。**

---

## 5. 软门禁（警告 + 人工复核）

- 自然改写的语义证据；
- 例题教学价值；
- 小结质量；
- 人设语气；
- UI 美观/可访问性。

软门禁不能替代硬门禁；硬门禁不过，内容不交付。

---

## 6. Definition of Done（每个功能）

一个功能只有同时满足以下 5 条，才叫“做完”：

1. **有代码**；
2. **有真实资料跑通的产物**（不是 mock/测试桩）；
3. **过 P0 门禁**（覆盖/出处/老师/答案/图片/语言/公式/系统）；
4. **有质量报告/证据**（可查看、可追溯）；
5. **用户能实际使用**（按钮可达、空/错/加载完整、无死链）。

缺一条，就是 🟡 或 ⬜，不能写 ✅。

## 7. 永不宣称（No-Claim List）

- 不说“四类生成可用”，除非四类各有真实样例过门禁。
- 不说“覆盖率 100%”，除非是页覆盖，不是资料存在率。
- 不说“答案可靠”，除非独立答案审计通过。
- 不说“三语言”，除非 UI 干净 + 语言角色正确。
- 不说“学习闭环”，除非练习→错题→复习→掌握度全链路跑通。
- 不说“可发布”，除非签名/公证/Windows/内测/盲测完成。
- 不说“全覆盖”，除非按“单份资料 ≤150 页”规则逐页覆盖，并列出缺失页。
- 不说“教材级”，除非标头/目录/摘要/分节出处/图片/结语/页脚/页码齐全。
- 不说“AI 无处不在”，除非每个页面都有入口、动作可追溯、可撤销、可验证。
- 不用“175 项测试通过”“160/160 任务成功”“549 个 KaTeX 节点”当内容质量证明。
