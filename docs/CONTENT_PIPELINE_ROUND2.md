# 内容管线第 2 轮：模型、提取、排版、答案校验（2026-11-12）

本轮不做首页、不做审计界面、不加按钮。只改四件事：生成模型/预算、提取覆盖、PDF 排版、答案校验。

## 1. 模型与输出预算

- 默认文本模型从 deepseek-flash 切到 deepseek-v4-pro（reasoning_effort=high）。
- 单次输出上限 8192 -> 16384，作者小节 max_tokens 6144 -> 12288，试卷批量 6000 -> 12000。
- 提取/练习这类短输出走 deepseek-flash，避免全量提取 10 分钟；讲义/出卷/逻辑分析走 Pro。
- DeepSeekClient 支持 model 参数；配置文件默认值改为 Pro。

实测：同一个 2 页解剖小节，旧 Flash 版 893 字；早期硬指标 Pro 版 2,124 字（但会诱发凑数）；改成按知识点/信息量写之后 1,003 字、8 个 block、1 个有效例题、padding 检测 0 问题。单节约 44 秒。

## 2. 讲义内容

- 写作 prompt 不再用字数/段数/例题数 KPI（固定指标会让模型用套话和假例题凑数）。
- 改为按资料信息量：
  - 先列本节 3–8 个知识点，逐点写；资料少就写短；
  - 每段必须推进新信息，禁止“本节介绍了/综上所述”空段；
  - 例题只为讲清某个知识点而写，必须有条件/步骤；没有就写短，不硬凑。
- 证据包每页上限 1800 -> 3000 字，减少密集页被截断。

## 3. 提取覆盖

- “全部资料”提取不再 12 页一大块，改为按资料自己的小节逐节提取再合并。
- 每节拿到自己的页码和原始页文本，避免模型只覆盖 12 页块的前几页。
- 实测 24 页解剖、8 节、全部资料提取考点：
  - 旧：26 条；
  - 新：35 条，页覆盖 100%，42.8 秒（Flash）。
  - 条目仍有“第 1 页章节标题”这种弱条目，但覆盖密度明显提高。

## 4. PDF 排版：两个真实 bug

### 4.1 Paged.js 注入位置错误

_with_pagedjs 原来替换第一个 </body>。阅读器 JS 的导出字符串里也有一个 </body></html>，结果 Paged.js 被插进 JS 中间，整个 JS 块被当正文印到 PDF 里（解剖学 Pro 讲义第 8 页全是 var ... function ...）。

修复：从最后一个 </body> 注入。

### 4.2 PDF 里印出阅读器工具条

之前依赖 @media print 隐藏，但 Paged.js 克隆 DOM 后仍会带出。现在打印前直接从临时 DOM 删除 .tf-reader-tools / .tf-search-bar / .tf-ai-panel / .tf-export-menu / .tf-practice / .tf-selection-tools。

修复后 10 页解剖 Pro 讲义：
- PDF 7 页，Gate 通过；
- 第 1 页从“课程讲义/解剖重构”开始，没有工具条、没有 JS；
- 正文 5,932 字（旧 24 页版 9,564 字，折合每页 593 vs 399 字）。

## 5. SymPy 答案校验

- 新增 tfv2/quality/math_verify.py：
  - 解析答案和解析末尾表达式；
  - 只在两者都是可解析、同类型（都是数或同符号集）时比较；
  - 不比较“数字答案 vs 函数定义”，避免误杀；
  - 检查简单算术等式。
- 已接入试卷审计；实测抓出：
  - answer -2/e^2 / analysis 1/e^2；
  - answer -4/3 / analysis -2/3；
  - answer 1 / analysis 0。
- 新增 tests/test_math_verify.py 4 项。

## 6. 试卷覆盖与答案审计

- Prompt 现在告诉模型“已用页 / 优先未使用页”，并要求同一页最多 1 题。
- 12 题 Pro 模拟卷实测：45.8% 页覆盖（旧 33.3%）、0 重复、0 自纠错、SymPy 0 问题；内容从“套公式”变成临床情境题。
- 答案审计有两个真实 bug：模型返回 A/B/C/D 而不是 0–3，旧代码 int() 直接失败；10 题一次审计又会被截断。现在按 5 题分批、支持字母、用 Pro low effort 审计。
- 审计仍有 1 题分歧（第 2 题 B/C），说明“模型自审”不是最终答案；下一步用题库/人工复核解决。
