# TermFinale 完整交接资料

> 新对话先读本文件。不要从旧对话摘要推断，不要相信“已完成”的口头说法；以本文件、代码和产物为准。

## 0. 任务性质

TermFinale 是大学期末复习平台，包含讲义生成、提取、练习、出卷、阅读器、错题本、笔记。

目标不是“能跑”，而是：

- 可发布
- 跨资料稳定
- 内容可解释
- 不丢页、不乱码
- 失败有原因，不静默降级

禁止用单个样张冒充通用能力，禁止把 partial 标成可读，禁止伪造页码、来源、图片。

## 1. 最终产品标准

### 1.1 通用资料

用户会上传：

- PDF
- PPT / PPTX
- DOC / DOCX
- 图片
- 扫描件
- 公式教材
- 混合排版资料

要求：

- 任意 1–2000 页
- 不能因为解析失败直接报错
- 必须有降级路径
- 扫描/公式/表格/图片页不能丢页
- 数学/公式页不得出现 `￿`、私用区字符、控制字符

### 1.2 讲义档位

按“单份资料总页数”判断，不按多资料合计：

| 单资料页数 | 可选档位 | 最低覆盖 |
|---|---|---|
| 1–50 | 无选择，标准 | 100% |
| 51–150 | 精品 | 70% |
| 51–150 | 高范围 | 85% |
| 151–500 | 普通 | 50% |
| 151–500 | 精品 | 65% |
| 151–500 | 高范围 | 75% |
| 500+ | 普通 | 50% |
| 500+ | 精品 | 50% |

补充：

- 500+ 不提供高范围。
- 所有档位都不得遗漏知识点。
- 大资料允许少图、概述、细节从简，但必须：
  - 基本框架完整
  - 目录完整
  - 摘要完整
  - 能读懂
  - 行文自然

### 1.3 多资料

用户可多选资料。

拼接开关：

- 不拼接：N 份资料 → N 份讲义
- 拼接：自然融为一体，一份讲义，文字可搜索

拼接不是 PDF 合订，必须：

- 统一主题与章节
- 章级过渡
- 同名概念去重
- 保留各自出处

拼接档位取各资料可用档位交集；无交集拒绝。

资料总页数不受其他资料影响。

### 1.4 每份讲义必须有

- 封面
- 摘要
- 完整目录（章节，不是“第 N 页”）
- 正文
- 每块出处/页码
- 结语
- 免责声明
- AI 声明

标题格式：

```text
顶部小字：TermFinale精品讲义 / 精品提取 / 精品试卷
大字：课程名
下方小字：讲义标题 + 课程基本信息（仅讲义）
页脚：免责声明 + AI 声明
```

### 1.5 最低内容标准

无论多少页：

- 能生成，不失败
- 公式不能乱码
- 排版清晰
- 说人话，能看懂
- 有基本知识点框架
- 行文自然
- 有摘要/目录/溯源/结语

## 2. 第一梯队标准

不要自称“第一梯队”“100% 完成”“工业级”，除非有真实验收证据。

第一梯队至少需要：

- 50 页以内逐页精准
- 51–150 有明确覆盖策略
- 151–500 有章节选择
- 500+ 有索引/分卷
- 多资料自然融合
- 所有模块共用同一页模型
- 公式/表格/扫描件不丢不糊
- 覆盖目标可验证
- 全量回归通过
- 失败有原因，不静默降级

当前未达到，禁止宣传为第一梯队。

## 4. 讲义流程

1. 选资料页
2. 宽弹窗缩略图
3. 全选 / 范围 / 任意页
4. 保存选择
5. 页内预览确认
6. 重新选择 / 同意继续
7. 全屏生成：阶段、百分比、已用/剩余、取消
8. 完成后可读、可编辑、可导出

档位弹窗要显示：

- 资料共多少页
- 可用档位
- 覆盖目标
- 高成本提醒
- 大资料细节/配图从简

## 5. 模块标准

### 提取

- 考点：可提取、可变式
- 名词：默认带解释；支持默写模式
- 原题：保留原题，不硬改选择题
- 逻辑分析：只做分析，不进入练习
- 公式/图片页：跳过或保留原图，不硬转乱码

### 练习

- 按讲义章节
- 按资料页
- 错题进入错题本
- 新错题当天到期
- 答题结果、解析、页码

### 出卷

- DIY 蓝图
- 真题风格
- 非题目文件必须显式确认，不静默切换
- 整卷、题型、分值、答案审计
- 计算/简答不冒充自动判对

### 阅读器

- 搜索
- 编辑
- 导出
- AI 侧边栏
- 选中文字问 AI
- 加笔记
- 出处/页码

## 11. 2026-11-16 进度与证据

原则：只写跑过的。每条都有复现命令；跑不过的不写“已完成”。

### 11.1 §7-1 / §7-3 多资料自然融合（已完成，确定性路径）

新模块 `tfv2/product/fusion.py`：

- 切章：用真实标题（`第X章` / `1.2.3` / `一、`，允许数字与标题间无空格），无标题才按页段兜底，标题写明“原文页段”，不伪装知识点；
- 统一章节：标题归一 + 章号 + 主题相似度 + 泛称后缀判断是否同一章；页段兜底章永不跨资料合并；重名章两边都带资料名/页段，不加“(2)”；
- 章级过渡：章内换资料时，在下文第一个块的页面上写一句“（衔接）下面换到《X》第 N 页”，不额外断言两份资料的关系；
- 同名去重：2-gram Jaccard ≥ 0.82 且 ≥120 字的重复页只讲一次，后出现的留定位，命中记入 `fusion_report.json`；
- 出处：每个 block 带 (资料名, 原资料页码)；`SourceRef.source_page` + scoping 写 `source_page` / `origin_pages` / `page_map`，裁切后页码不再失真，多资料出处按《资料名》分列；
- 失败有原因：每节记录 `mode`（authored/digest）、`fallback_reason`、`backfilled_pages`；要求模型成文但没有客户端时直接报错，不退回 digest。

`combine.py` 明确三分：`fuse`（融合）/ `append`（合订本，manifest 标 `merge_mode=append`）/ 不拼接 N→N。

复现：`.venv/bin/python scripts/fusion_e2e.py`

| 用例 | 内容 | 结果 |
|---|---|---|
| A | 模电 1–8 + 数分 1–8（不同科目） | 16 页 / 5 节 / 跨资料章 0（不硬合）；HTML 逐行可搜 12/12；PDF 中文 9273 字 vs 资料 8524 字（文本版） |
| B | 同一教材 1–8 + 5–12 | 1 章跨资料合并、1 处重叠去重、1 处过渡句；出处回到原书 1–8 / 5–12；两份资料可区分 |
| C | 两份真实扫描件 12 页 | 12 张原页影像、无丢页、无乱码 |
| D | 不拼接 | 2 份独立讲义，各自只引用自己的资料 |

模型成文路径（`--author`，DeepSeek）：用例 A 实测 5/5 节全部 authored（无降级），
耗时约 9 分钟，PDF 正文中文 7051 字（资料 8524 字），40 个资料术语命中 23 个，
出处/原页码/无乱码检查全部通过。

单测：`tests/test_fusion.py`（31 条）。

### 11.33 失败根因优化：漏页补原文、坏批次不拖垮整卷（2026-11-17，第十九轮）

按“不要只加失败原因，要想为什么失败”的要求，这轮只改算法本身：

**A. 讲义“页面没被引用”类失败（最高频）**

- 根因：模型常只引用部分页；第二次仍漏就整节失败，白烧一整节 token 还交付不了；
- 修法：新增 `_fill_missing_pages`，把漏掉的页用**资料原文**补成块（“资料补充（第 N 页）”），
  空白/图片页写明；补完就不再因“漏页”判失败；
- 顺带修掉一处旧逻辑只给空白页补说明、文字页反而跳过的问题；
- “高权重重点只展开一次”改为只在**第一次**要求重写，第二次不再判死（`_accept_issue`）。

**B. 出卷“一批返回结构不对”直接整卷失败**

- 根因：`raise ExamError("模型没有返回 questions")` 在批循环里，异常没被吞，整张卷直接失败；
- 修法：记一条问题并 `break` 到已有的“逐题补题”兜底，继续出卷。

**C. 讲义“内容体检未通过”的根因：公式块混排 / 段落里带 TeX**

- 小样本实跑（教材 2 页）第一次结果：`gate=false`，原因「公式块之外出现 TeX 命令」——
  这不是模型“写错内容”，而是我们没在生成路径收口公式（融合路径早就有了，生成路径漏了）；
- 修法：把收口逻辑抽成 `authoring.normalize.sanitize_section_math`，
  - 段落里的 TeX → 纯文本（`R_{\mathrm{o}}` → `Ro`）；
  - 混排的“讲稿式公式” → 按段落处理；
  - 干净公式仍包一层 `$$`；
  融合与讲义生成共用这一套；生成最后一步统一过一遍；
- 复跑同一份 2 页资料：`gate=true`，**从“未通过”变为可读**（255s，本地渲染）。

单测：`tests/test_generate_page_fill.py`（6 条）+ `tests/test_metrics.py::MathSanitizeTests`（3 条）。回归：**808 tests OK**。
