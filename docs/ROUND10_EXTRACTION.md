# 第 10 轮完成报告：提取引文 + 近重复合并（2026-11-13）

## 做了什么

- 考点/名词/原题的输出 schema 都要求 quote：原文一句，逐字摘录。
- 引文校验：引文必须在对应页原文中逐字出现；模型没给/给错时，从原文句子中选重叠度最高的一句补上；补不上就丢弃该条，并记录“缺原文引文”。
- 跨节近重复合并：按考点/术语/题干归一化后，精确相同、相似度≥0.88 或词 Jaccard≥0.8 的合并；保留第一条，合并页码区间，记录 duplicates_merged。
- 分节提取改为每 6 页一块，避免 12 页大块让模型只写前几页；单块 Flash 空返回时用 Pro-low 兜底。
- 单节失败不再让整份提取直接崩，继续跑其他节。

- 召回/准确率的人工 gold set 还没做；本轮只验“有引文、无近重复”。
