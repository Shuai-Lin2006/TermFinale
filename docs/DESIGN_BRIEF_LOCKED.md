# TermFinale 内容锁定 Brief（2026-11-09 更新）

> 2026-11-09 起，讲义标头/目录/摘要/分节溯源/图片/结语/页脚/教材排版以 `docs/ULTIMATE_FORM_LOCKED.md` §2.2 为准；本文件保留版式底线。

## 用户底线
- 生成内容必须能读懂、能复习、能提分；不是报告/卡片/PPT 拼接。
- 不允许“原文/讲解/图示/配图/P.x/页码索引/这一页/这张卡”等机器标签。
- 图片必须白底、干净、与段落对应；PPT 截图、彩色背景、页码、水印不得进正文。
- 必须有：标头、教材式目录、全篇摘要、章节正文、分节溯源、结语、页脚。
- 正文要保留老师人设语气（提醒、易错、记忆法），但不要每段都贴标签。
- 数据/角度/对比用表格或分点，不用长串文字堆砌。
- 结构/构象（椅式、船式、a/e 键）必须有清晰示意图，不能只靠文字。
- 先前约束全部继续有效：全量内容、公式正确、答案可核、测试隔离、Word/PDF 可用。
- 不得用工程指标（页数/测试数）替代产品质量。

## 版式
- 目录：普通层级列表，不用卡片；目录后分页；不得截断。
- 正文：段落间距、首行缩进；关键术语加粗；重点用少量“提醒/易错”块。
- 溯源：每小节末尾一行小字出处（第 X–Y 页）；正文内不出现 P.x；章末汇总。
- 标头：标题 + 用户情况（目标/天数/基础/资料数/覆盖）；人设只影响生成语气，不写入标头；无 App、开发者、随机祝福、源文件名。
- 页脚：所有 AI 生成资料末尾一行小字生成声明（智能体/覆盖率/资料名/免责声明），不影响阅读。
- 排版：教材式，不要大卡片/大色块；该换行就换行；打印页码；图注小字。
