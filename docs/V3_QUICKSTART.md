## 页面

- **今日**：继续学习、今日到期错题、可读/待复核/未通过计数。
- **讲义库**：7 份现有 artifact；可读 1 份（电路全章），其余 6 份待复核。
- **质量报告**：Gate、内容/PDF/语言体检、语义覆盖、图源、缺失页、小节列表。
- **阅读**：标题下摘要 → 目录 → 第一章/第一节正文；v2 搜索/编辑/选中 AI/导出 + v3 外层返回/练习/PDF。
- **练习**：按小节出单选题；服务端判分；答错进错题本。
- **复习**：到期错题、1/2/4/7 天复习、按真实答题算掌握度。
- **笔记**：阅读器选中文本“存笔记”，这里汇总/删除。
- **工作台**：提取考点/名词/原题/思维导图；题目支持选择题/计算题/简答题，选择题有独立答案审计，计算/简答答案标“需人工审计”；`全部资料` 选项覆盖整份 artifact。
- **出卷**：真题参考/自定义蓝图，四种模式（原题改数/原题变式/模拟/预测），满分 100，科目题型/难度/配图说明/三审答案；试卷可打印、导出 HTML/Word、直接编辑。
- **新建**：单份 PDF/PPTX/DOCX/PNG/JPG/WEBP，或多份合并（最多 6 份，权重 1–5，高权重切得更细/篇幅更长）；优先资料大纲，单份 ≤159 页补齐全文页，重点/不考字段进 prompt 并做关键词硬检查；自动页图+视觉图注，过 Gate 才进库；最多“待复核”。
- **AI 助教**：全站右下角，随时解释/出题/7 天计划/提炼重点/自由对话；有当前讲义时走检索并标页码，无讲义时是通用学习助手；会话持久化。
- **个人资料**：左下角姓名/首字母头像，设置里可改称呼，只存本机。
- **设置**：主题、简体/繁体/English、称呼、Key 状态、模型、数据库路径。
- **生成语言**：新建/多资料/工作台/出卷都可选简体/繁體/English；讲解用生成语言，资料原文引用/术语保留原语言。
- **学科图**：电路/物理用结构化模板，化学用 RDKit（SMILES），数据结构/流程用程序画，医学/生物优先原图。
- **AI 装饰图**：Qwen-Image-3.0，约 $0.025/张，默认关；只放讲义，不冒充精确图；同一个百炼 Key，不用另注册。
- **示意图**：出卷优先资料原图；无原图时，简单串联电路用结构化模板重画，并在图注标“AI 结构示意图，请核对”；复杂拓扑不硬画。
- **Agent 任务**：AI 抽屉“执行任务”可规划检索/读页/复习计划/练习跳转；写操作只给 action，需确认。
- **异步任务**：讲义/多资料/试卷/任务都可后台运行、看进度、取消；试卷和任务结果落库后仍可导出。
- **整份 AI 改写**：质量报告页或全站 AI 抽屉都可发起；生成新草稿（原稿不动）、逐节 diff、重新过 Gate/PDF；可一键替换原稿（自动备份）或恢复上一版。

## 质量口径

- **可读** = 结构 Gate + 内容/PDF/语言体检 + 语义审计 0 partial / 0 missing / 0 visual / 0 empty。
- **待复核** = Gate 过了，但没有语义审计，或有 visual/empty/partial/missing。
- **未通过** = 任一硬门禁失败。
- 0 次练习的掌握度显示“—”，不是 100%。

## v3 没做什么

- 四类任务只过了机器门禁，没有人工复核/golden set；原题逐字检查用讲义文本，可能误杀。
- 自动配图是“视觉模型识别 + 页锚定 + 与段落 2-gram 匹配”，仍不是学科专家确认；图注会写明需人工复核。
- 原生 Word 只覆盖讲义（`.docx`，含图/公式转文本），四类任务/分析没有 Word 导出；Word 版式未在 Microsoft Word 客户端验收。
- 逐页结构排查见 `docs/evidence/v3_page_audit.md`：`v2_ring_41`、`v2_ring_41_gentle` 两个旧样例因缺 block 页已归档到 `data/archive/legacy_artifacts/`，不再进库/审计；`v2_ring_full` 的 visual 页已从缺页统计中排除，缺 0；`v2_medical` 没有 `sections.json`，无法做 block 级页覆盖。
- 生成物没有自动语义审计，所以不会自动变“可读”。
- AI 目前能问答/出题/计划/提炼，不能直接“重写这一节/生成整份讲义”并撤销；写操作规划器未做。
- 图片/扫描件输入已接 OCR（图片写不可见文本层；扫描 PDF 低文本页自动 OCR）。
- AI 写操作（重写某节/生成整份讲义并预览撤销）未做。
- 打包/签名/公证/Windows/内测/盲测未做。
