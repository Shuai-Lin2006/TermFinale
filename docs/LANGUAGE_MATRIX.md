# 语言矩阵与质量边界（2026-11-14）

## 实测

| 组合 | 样本 | 结果 | 耗时 |
|---|---|---|---|
| 英文资料 → 英文生成 | 3 页 English Kinetics PPT | **0 个中文字符**；无 mojibake；119.3s | 通过 |
| 中文资料 → 英文生成 | 2 页解剖 PDF | 2025 拉丁字符 / 2 个中文字符（0.1%，术语/原文）；无 mojibake；189.5s | 基本通过 |
| 英文资料 → 中文生成 | 3 页 English Kinetics PPT | 中文正文；保留 17 个英文术语；7 个术语缺失 warning；gate 通过 | 通过（有 warn） |
| 中文资料 → 中文生成 | 24 页解剖 | 既有 24 页 validated 样本 | 通过 |

## 能承诺的

- 目标语言硬门禁：生成语言 English 时，正文中文占比 >50% 直接 hard fail；
- 乱码门禁：U+FFFD、“锟斤拷”、常见 mojibake 直接 hard fail；
- 页码/来源：每条内容可回指页；
- 图片相关性：视觉复核 + 超时 fail-closed，不默认保留未验证图；
- 公式/表格失败：转图或保留原图，不输出半截 LaTeX。

## 不能承诺的

- **不能保证语义 100% 无遗漏**：100 页页覆盖可 100%，语义靠 gold set；
- **不能保证 0 错图**：10 页 3/3 是样本，不是统计保证；复杂图/相似图仍可能错配；
- **不能保证英文扫描件/手写**：文字层英文支持，扫描英文没有验收；
- **不能保证所有复杂表格/公式完美**：合并单元格、跨页拆分、超长公式仍会降级为图；
- 字体：中文部分字体有 n/a，跨机器仍有替换风险。

## 四种语言组合怎么保证不错乱

- 语言合同：source_lang / gen_lang / quote_policy / term_policy；
- 原文引用保留原语言，但标注“原文引用”；
- 英文术语保留 + 中文释义，避免译文把术语翻丢；
- 中文资料→英文生成：允许保留少量中文专名，但正文必须英文；
- 英文资料→中文生成：英文术语保留，正文中文；
- 输出后跑语言检查：目标语言占比、乱码、术语保留率。

## 还没做

- 四种组合的 **PDF/Word 排版专项验收**（目前只验了正文文本）；
- 100 页英文/中英混合的页覆盖与基准；
- 扫描英文 OCR；
- 语言门禁的永久测试（当前是手工脚本 + 代码检查）。

## 结论

语言不会“自然错乱”，因为已有目标语言/乱码门禁；但**不能说绝对不出错**。
