# 50 页三解析器对比（2026-11-16）

同一 100 页第一章 30–79 页，50 页扫描教材。

| 指标 | Docling | MinerU flash | PyMuPDF |
|---|---:|---:|---:|
| 页数 | 50 | 50 | 50 |
| 文本字符 | 34,843 | 29,740 | 0 |
| 图 | 79 | 104 | 50 |
| 公式块 | 混在文本 | 197 | 0 |
| blocks | 2302 | - | 0 |

## 结论

- 扫描件上 PyMuPDF 不可用；
- Docling 文本更完整、blocks 更细；
- MinerU 公式块 197、图 104，公式/图更强；
- 生产应采用并集：Docling 文本 + MinerU 公式/图；
- 只测 50 页，不是 300 页。

## 成本

- MinerU 本地 flash，不烧 API；
- 但要 1.2G 环境和本地服务。
