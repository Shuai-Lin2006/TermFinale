# TermFinale 最终路线（冻结版 v3，2026-11-12）

> 唯一依据。以后只说“做第 N 轮”，就只做第 N 轮写死的范围。不临时加功能、不重复上一轮、不顺手改 UI。
> 本版新增：用户排除语义系统、不交付治理、UI 理解原则、产品建议、14 轮固定表。

# 0. 先判断：空谈还是能实现

- 能实现：课程制工具，讲义/练习/出卷/提取四条线，每条线在固定样本上达到写死指标，并且不低于指定开源基线的 90%。
- 不能证明：“用户随便找任何工具、问任何 AI，都不如这个软件”。这句话无法验收。
- 承诺：14 轮后，第 7 节验收指标 100% 达标；不承诺“宇宙最强、永远无人超过”。
- 每轮必须一次交付；做不到就停在本轮，写清卡点，不进入下一轮。

# 1. 现在能干什么（大白话）

- 上传 PDF/PPTX/Word，出带章节、例题、易错点、小结的讲义。
- 讲义插资料原图，图小完整；PDF 干净，Word 有图、有真表格。
- 干净公式 OCR 成 LaTeX；不可靠的保留原图，不乱码。
- 按小节提取考点/名词/原题；24 页解剖约 35 条、42.8 秒。
- 出 100 分卷：真实背景题、解析、答案；15 题 Flash 约 3.7 分钟。
- 用户说“某章不考”，讲义整节跳过（当前只做字符串匹配，不够）。
- 408 项测试通过；源码预览 8917 可用。

## 2.1 左侧栏（9 个入口）

## 2.2 首页总控台（轨道）

课程、练习、复习、出卷 + 工作台面板。
问题：首页四个节点 = 侧栏四个入口 = 课程页五个 Tab。

概览、讲义、范围工具、训练、试卷。
另有：生成讲义/编辑资料、打开内容工具、练这一节、打开讲义、PDF/Word、重命名、删除、归档。

## 2.4 工作台（内容工具）

生成讲义、提取考点、提取名词、提取原题、逻辑分析、思维导图、出卷、练习。
问题：它既是入口，又和课程页/侧栏互跳。

## 2.5 重复入口计数

- 练习 4 个：侧栏、首页、课程训练、练习 CTA。
- 出卷 4 个：侧栏、首页、课程试卷、工作台。
- 提取/内容工具 4 个：侧栏、首页面板、课程范围工具、课程卡。
- 课程 3 个：品牌、侧栏、首页。
- 讲义 3 个：课程概览、讲义 Tab、工作台。

# 3. 用户排除语义系统（写死）

## 3.1 为什么要改

用户不会只说“第 3 章不考”。他会说：
- “积分中值定理不考”
- “这个考点不考”
- “老师说不考泰勒展开”
- “计算题不考，只考选择”
- “第 20 页不用看”
- “别考生僻词”
- “实验部分跳过”
- “我们只考到第 5 章”

当前只做字符串匹配、只删整节，不够。必须解析成结构化排除，再在资料里定位相关内容，过滤讲义、提取、出卷、练习。

## 3.2 结构化排除对象

每条排除解析为：
- scope：page / section / topic / keyword / question_type / whole_material
- value：用户原话里的对象（如“积分中值定理”）
- normalized_terms：标准术语 + 同义词 + 英文名 + 缩写
- applies_to：lecture / extract / exam / practice 的组合
- confidence：0–1
- source_quote：用户原话
- matched：命中的页码、小节、考点、题号

## 3.3 解析流程（五步）

1. 意图解析：LLM 把自然语言转成结构化排除；无法确定 scope 就标 ambiguous。
2. 术语扩展：同义词/英文/缩写；只扩到语义等价，不扩到相邻概念。
3. 资料索引：用页文本、节标题、考点/名词条目、题号，建立“术语→位置”索引。
4. 匹配与预览：算出“将排除：第 12–14 页、3 个考点、2 道题、1 张图”；confidence≥0.9 自动，否则必须让用户确认。
5. 执行与留痕：写 exclusion_report.json；讲义/提取/出卷读同一份规范；提供“撤销排除”。

## 3.4 安全规则（防止误删）

- confidence < 0.9：不自动删，先问“你是不是指 X？涉及 Y 页/Z 条”。
- 命中超过资料 30%：必须确认，防止“不考”被理解成“整本不考”。
- 只匹配到页眉/标题/目录：不删正文，标“仅标题命中”。
- 术语歧义（如“积分”既指章节又指计算）：列出候选让用户选。
- 用户说“不考”但该内容在真题里高频：提示“该考点近 3 年出现 2 次，仍要排除吗？”
- 所有排除可撤销；撤销后重新生成相关部分。

## 3.5 必须覆盖的输出

- 讲义：计划阶段跳过相关页/段；写作 prompt 明确“不要讲 X”；图/表相关也过滤。
- 提取：考点/名词/原题结果里不出现 X；统计“已排除 N 条”。
- 出卷：蓝图和题目不考 X；真题参考里 X 不作为变式来源。
- 练习：不生成 X 的题；错题本里 X 标“已排除”。
- UI：排除以 chip 显示（“不考：积分中值定理 ×”），可点开看命中范围、可撤销。

## 3.6 验收

- 20 条自然语言排除样例，意图解析准确 ≥95%。
- 误删 0：不该删的正文/题不能被删。
- 四类输出（讲义/提取/出卷/练习）全部遵守同一排除规范。
- 每条排除有 source_quote、matched、confidence、可撤销。
- 歧义样例必须提问，不允许猜。

# 4. 不交付治理（写死）

## 4.1 问题

现在门禁一失败就 rejected，用户拿不到东西；出卷覆盖 4–20% 直接拒绝；讲义 PDF 失败只给草稿。用户要的是“能用”，不是“完美才交付”。

## 4.2 交付状态（四档）

- validated：硬指标全过，可直接用。
- review：内容完整，但有软问题（覆盖略低、1 题待审、审计未完成），可打开、可导出，标“待复核”。
- partial：缺页/缺题/缺图，但主体可用；明确列出缺什么，可导出，可续跑。
- rejected：只用于硬错误（总分≠100、答案矛盾、重复题超阈值、无页码、崩溃）。

## 4.3 硬错误 vs 软问题

硬错误（必须拒绝）：
- 总分不等于 100；题数严重不足（<计划的 50%）。
- 答案与解析矛盾；SymPy 校验失败；选择题答案冲突未解决。
- 近重复题超过 20%；自纠错痕迹。
- 没有任何有效页码/来源。

软问题（交付为 review/partial）：
- 页覆盖 35–45%；单题审计冲突；审计服务超时。
- 少 1–2 张图；表格结构不完美；Word 公式是图。
- 讲义某节偏短；图注待核对。

## 4.4 交付保证

- 任何产物都不静默删除；失败也保留 artifact。
- 所有状态都能导出 PDF/Word/CSV（能导多少导多少）。
- partial 必须显示“缺哪几页/哪几题/哪张图”，并提供“补齐并重跑”。
- 后台任务可断点续跑；超时/限流不整卷丢弃，保留已完成部分。
- UI 状态 chip：可读 / 待复核 / 部分交付 / 未通过；点开看原因和下一步。

## 4.5 验收

- 10 个失败场景：0 静默丢失；partial 全部可导出；硬错误 <5%。
- 出卷 5 张：≥4 validated，剩余至少 review/partial，不得全部 rejected。
- 讲义 PDF 失败：必须给可读草稿 + 缺页清单。

# 5. UI 理解与重构（写死）

## 5.1 八条原则

1. 一个对象只有一个家：课程只在学科里，讲义只在课程里。
2. 一个动作只有一个入口：练习/出卷/提取各一个主入口。
3. 课程是容器，功能是动词：课程页只放四个动词。
4. 全局只放跨课程的东西：搜索、设置、说明、用户。
5. 渐进披露：首页看学科，学科看课程，课程看功能，功能看结果。
6. 空状态必须给下一步，不给死路。
7. 状态可见：生成中/待复核/部分交付/失败，都在卡片上。
8. 返回路径固定：任何页面都能回到学科/课程，不靠浏览器后退。

## 5.2 新结构

- 侧栏：品牌 + 搜索 + 学科列表 + 新建学科 + 设置/说明/用户。
- 首页：继续学习 + 学科卡片；唯一 CTA 新建学科。
- 学科页：头部信息 + 四张功能卡（讲义/练习/出卷/提取）+ 课程卡片。
- 课程页：四个 Tab（讲义/练习/出卷/提取）+ 齿轮设置。
- 工作台取消一级；提取成为功能页。
- 复习并入练习；笔记收进课程。

## 5.3 路由

- 首页 /
- 学科 /s/:subject
- 课程 /s/:subject/c/:course/:tab
- 设置 /settings
- 说明 /guide

旧路由全部重定向：/library、/practice、/review、/exam、/workbench、/course/:key/*。

## 5.4 UI 验收

- 重复入口 0；每功能一个主入口。
- 点击深度 ≤3；每页一个主 CTA。
- 旧路由全部可达；无死链。
- 1440/390 无横向滚动；空/加载/失败态齐全。
- 键盘可达、焦点可见、aria-label 完整。

# 6. 产品建议（写进路线或 backlog）

1. 覆盖热力图：哪几页没讲、哪几页没出题，一眼看到（第 3/7 轮验收用）。
2. 段落级重生成：只重写一段/一题，不整份重跑（第 12 轮）。
3. 引文悬浮：鼠标悬停看原文，点开跳页（第 4 轮）。
4. 一键导出 CSV/Anki：考点、名词、错题（第 4 轮）。
5. 成本/耗时面板：每次生成花了多少 token/钱/分钟（第 14 轮）。
6. 版本对比：讲义 v1/v2 差异，可回滚（第 14 轮）。
7. 断点续跑：长任务失败可续，不从头（第 2 轮）。
8. 难度校准：按真题频次/目标分给题目标难度（第 3/8 轮）。
9. 考试倒计时 + 今日建议：只做“今天该复习哪节”，不造焦虑（第 13 轮）。
10. 本地优先/隐私：资料不出本机；模型调用可配代理（第 14 轮）。

# 7. 最终验收标准（写死）

## 7.1 内容

1. 出卷：5 张，≥4 validated；覆盖≥45%；0 重复、0 自纠错、0 答案冲突；≤5 分钟/张。
2. 提取：50 页 gold set 召回≥85%、准确≥85%；跨节近重复 0；每条有原文引文；名词含英文/缩写；原题含年份/题号/分值/答案校验。
3. 公式：20 条抽测 ≥80% 转可渲染 LaTeX；其余保图；PDF/Word 无乱码。
4. 表格：5 张真实表格 ≥4 张结构正确；PDF/Word 真表格。
5. 图片：插图准确≥90%，资料图召回≥70%，0 错图。
6. 讲义：24 页整本 Gate 通过，页覆盖 100%，padding 0，≤10 分钟，图≤页面 25%。
7. 排除：20 条自然语言样例准确≥95%，误删 0，四类输出全遵守。
8. 交付：10 个失败场景 0 静默丢失，partial 可导出；5 张卷无全 rejected。

## 7.2 UI

1. 重复入口 0；每功能一个主入口。
2. 点击深度 ≤3；每页一个主 CTA。
3. 旧路由全部重定向；无死链。
4. 1440/390 无横向滚动；空/加载/失败态齐全。
5. 课程制流程 ≤3 次跳转。
6. 键盘可达、焦点可见、aria-label 完整。

## 7.3 基准对比

- 解析/公式/表格：20 页样本跑 MinerU、Docling、Marker、Pix2Text；我们不低于最好者 90%。
- 提取：50 页 gold set 对比 LLM 直提；记录召回/准确。
- 出卷：同课程 5 张对比“直接让 AI 出卷”；记录覆盖/重复/冲突/耗时。
- UI：同一任务计时与步数；入口数 1，步数 ≤3。

# 9. “每轮一次完成”的定义

- 一轮只在一个会话内完成，交报告 + 可运行代码 + 测试结果。
- 不允许“本轮做一半，下轮继续”；做不到就停下写卡点，不进入下一轮。
- 每轮开始/结束各跑 408 测试；失败只修本轮范围。
- 每轮最多重试 2 次；仍失败如实报告，不假装通过。

# 10. 规则

1. 严格按 14 轮表执行；不临时加“顺便优化”。
2. UI 前 8 轮不动；第 9 轮只去重路由，第 10 轮起改视觉。
3. 排除系统必须全链路生效，不能只在讲义删。
4. 任何失败都不能静默删除产物；partial 必须可导出。
5. “最强”按第 7 节指标 + 基准对比判定，不按感觉。
6. 本文件冻结；要改必须单独说“改路线”，否则不改。
