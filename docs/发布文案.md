# TermFinale 发布文案与节奏

> 目标：把「大二学生做的免费期末复习工具」讲清楚，引导到下载页和 QQ 群，不夸大、不承诺分数。

## 一句话定位

**把几百页课件，变成带原书页码、能打印的期末讲义。**

## 三条内容，分三天发

### 第 1 条：为什么做（人设 + 痛点）

**B 站 / 小红书标题**

- 大二学生，花了半年做了一个期末复习工具
- 老师不划重点，我把教材做成了能直接背的讲义

**正文骨架**

1. 期末的痛：PPT 几百页、图文混排、不知道看哪
2. 试过速成课、AI 总结，但不知道对不对
3. 所以自己写了一个：导入资料 → 选页 → 生成带页码的讲义
4. 免费、开源、资料只存本机；模型用你自己的 Key
5. 现在找 10 个人内测，评论区/私信「内测」

### 第 2 条：真实演示（最重要）

**B 站 60–90 秒脚本**

- 0–5s：打开一份 200 页 PDF，「这是我这学期的一门课」
- 5–15s：选 8 页 → 生成 → 先看 2 页预览
- 15–35s：讲义页面，指页码：「每段都能翻回原书」
- 35–50s：练习题 → 判分 → 错题本
- 50–60s：下载页 / 免费开源 / 内测方式

**小红书图文 6–9 张**

1. 封面：`老师不划重点？我把教材做成了讲义`
2. 原 PDF 截图（打码课程名）
3. 选页界面
4. 讲义正文（展示页码）
5. 质量报告
6. 错题本
7. 下载页
8. 内测说明（10 个名额、免费、需自备 Key）
9. 评论区引导

**抖音 15–30 秒口播**

> 期末老师不划重点，PPT 几百页看不完。
> 我做了个工具：导入课件，选几页，生成带原书页码的讲义，还能出题。
> 免费开源，正在找 10 个人内测，评论区扣「内测」。

- **B 站**：简介和置顶评论可以放官网、GitHub、QQ 群；视频里口播「简介有链接」
- **小红书**：正文不要直接放长链接，容易被限流；引导「评论区/主页/私信关键词：内测」

- 不承诺「提分」「包过」「押题」；明确 Beta、内容可能出错、以原书为准
