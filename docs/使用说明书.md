# TermFinale 使用说明

> 与软件内「说明 → 使用说明」同步。

## 第 0 步：打开软件

1. 双击 TermFinale
2. 欢迎页点「开始设置」
3. 第二页点「继续」
4. 第三页填资料，点「完成，进入总控台」

## 第 1 步：填名字和学校

1. 名字：显示在左下角和问候语，之后可改
2. 学校：填全称，会自动带出校徽
3. 层级：按实际情况选，没有就选「其他」
4. 专业：用于生成时参考

## 第 2 步：填 DeepSeek Key（必填）

1. 打开 platform.deepseek.com，登录
2. 「API keys」→「创建 API key」，复制以 sk- 开头的字符
3. 回到 TermFinale：设置 → 模型 → DEEPSEEK API KEY，粘贴
4. 点「保存 Key」，再点「测试连接」
5. 看到「连接正常」即可

## 第 3 步：阿里云百炼 Key（可选）

1. 打开 bailian.console.aliyun.com，登录
2. 「API-KEY 管理」→ 创建，复制
3. 粘贴到「阿里云百炼 API KEY」，保存并测试

## 第 4 步：Kimi Key（可选）

1. 打开 platform.moonshot.cn，登录
2. 「API Key 管理」→ 创建，复制
3. 粘贴到「KIMI API KEY（可选）」，保存并测试

- Key 只写入本机 .env，页面不回显；填错覆盖即可，留空不修改。

## 第 5 步：新建课程

1. 课程库 →「＋ 新建课程」
2. 填课程名、目标分、考试日期、学分、难度
3. 上传资料，点「保存资料」

## 第 6 步：选几页预览

1. 资料卡里输入页码，如 701-708
2. 点「预览」，等生成完成
3. 公式多的页会显示原页影像，属正常

## 第 7 步：生成讲义

1. 课程页点「开始生成」
2. 右下角查看进度和剩余时间
3. 完成后课程页出现讲义卡，标「可读」

## 第 8 步：看质量报告

- 基础检查：结构、文字、版面、语言
- 内容检查：逐页是否讲到，需点「补充检查」
- 配图：可用图片数
- 讲义覆盖：讲到的页占比
- 内容质量：有依据比例、重点词覆盖

## 第 9 步：阅读与导出

1. 点「开始阅读」
2. 顶部可搜索关键词
3. 每段下方标原书页码
4. 右上角可导出 PDF 或 Word

## 第 10 步：出题练习

1. 练习 → 选课程
2. 选讲义，或选「按资料页」填页码
3. 选题量，点「开始出题」
4. 作答提交，看对错、答案、解析和页码

## 第 11 步：错题本

1. 答错的题自动进错题本
2. 错题本顶部看今日到期、已排期、错题总数
3. 点开今日错题重做，系统调整下次复习时间

## 第 12 步：出模拟卷

1. 课程页 →「出卷」
2. 填题量、总分、题型
3. 生成后导出

- 答案审计发现冲突时，整卷会标「需重做」并列出原因。

## 第 13 步：AI 助教

1. 点右下角「AI」
2. 直接提问，或点「解释这一节」「出 2 道题」
3. 回答下方页码可点回讲义
4. 复杂问题开「深度思考」

## 第 14 步：笔记与备份

- 阅读时选中文字 →「存笔记」，按课程归档
- 左侧「笔记」查看
- 左上角搜索（⌘K）搜课程和讲义
- 设置 → 备份 → 下载 ZIP

## 常见问题

- 生成慢：要读资料、写正文、排版、跑检查，页数越多越久
- 公式页是图片：公式识别可能出错，原页影像更可靠
- 模型返回为空：先测试连接，再重试或换几页
- 离线：资料和笔记在本机，生成和问答需要联网
