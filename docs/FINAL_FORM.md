# TermFinale 最终形态（最终验收标准）

> 这份标准只升不降。未过门禁不叫完成，不用“主题/页面/概览”冒充。

## 1. 内容覆盖底线
| 资料页数 | 要求 | 当前证据 |
|---|---|---|
| ≤150 | **精准全量 100%**，不遗漏、不瞎编、逐页可溯源 | 85 页：85/85 页，占位 0 |
| 150–1000 | **≥85%** | 171 页：169/171 = 98.8% |
| >1000 | **≥60%** | 1001 页：773/1001 = 77.2%；标“大幅覆盖” |

所有生成内容必须有页码/原文依据；页面覆盖率不等于每句正确，逐句证据链另立门禁。

## 2. 可读性与排版
- 公式无乱码；`$`/KaTeX 错误为 0。
- 图文精准配对 ≥99%；图片尺寸不溢出、不压正文。
- 阅读页：导出、编辑、搜索、选中任意内容问 AI，全部可用、无报错、无明显卡顿。
- 不设任意页数硬截断；长文用自适应分块，禁止静默丢页。

## 3. 意图理解与人机交互
- 规则 + 模型结构化抽取 + 用户确认的 **Study Contract**；
- 必考/不考/薄弱点/页码/每份资料权重/老师原话/置信度；
- 不硬编码具体科目；需要 50–100 条未见过的口语样例回归；
- 生成前确认、生成后证据复核、用户可纠正；AI 交互覆盖全流程，不只生成页。

## 4. 权重与个性化
- 资料权重真实影响：上下文/章节/例题/篇幅预算，不只是提示词；
- 人设、目标分、基础、剩余天数影响难度与讲法，但不能走极端；
- 高权重资料优先，低权重只补充；用户可在生成前看到并修改分配。

## 5. 生成与校验
- 逐份资料、逐题型测试；真实文件矩阵，不只合成数据；
- 试卷：结构、题题有答案、选择题字母合法、双解一致性；语义正确单列；
- 无法验证的答案必须标“需人工复核”，不能假装正确。

## 6. 学习闭环（以提分为核心）
- 诊断测 → 章节掌握度 → 今日 5 题 → 错题 → 间隔复习 → 再测；
- 以“这一章没掌握，先做这 5 题”替代题堆；
- UI 重构围绕一个焦点，不堆无用功能。

## 7. 三语言 / 主题
- 简/繁/EN、深/浅/跟随系统、5 主题色，全局持久化，所有页面一致；
- 保留辅助主题色，不做假切换。

## 8. 评估
- 同一批真实资料，TermFinale vs 顶级模型+强提示词，用户盲评；
- 准确、可溯源、覆盖、学习收益；未对比前不宣称超过顶级 AI。

## 9. 发布
- GitHub + 网页版 + Windows 测试 + macOS 签名/公证；
- 发布工程最后做，但目录/依赖/构建脚本从现在就保持可打包。

## 当前状态（诚实）
- 已过：127 测试、85 精准页账本、171 ≥85%、1001 ≥60%、试卷 100% 答案、PDF 单文件导出、token 安全。
- 未过：逐句证据链、图文 99% 配对实测、全部阅读功能回归、答案语义双解、意图泛化测试、学习闭环、UI 大重构、评估、签名/Windows。

## 10. AI 贯穿全流程（P0）
- 课程级 RAG：每份资料建页码索引；提问检索相关页，不只依赖选中片段。
- 全局 AI 抽屉：首页/课程/阅读/复习/错题/生成页随时可用；自动带课程、资料、章节、选中内容、历史。
- 生成前：AI 编译 Study Contract（必考/不考/薄弱点/页码/权重），用户确认。
- 生成后：逐句证据复核；用户可追问“依据在哪/为什么这么讲”。
- 错题：解释错因、给同类题；复习计划：解释“为什么今天做这些”。
- 回答规则：有资料出处才写；没有就明说“资料未涉及”，不装懂；通用常识必须标【延伸】。
- 模型路由：问答/证据用强模型，结构化抽取用便宜模型；历史可存笔记。

## 11. 题目与图文质量（P0）
- 题干必须有背景/条件/数据；没有数据就明确“只考方法”，禁止编造数字。
- 需要图：优先资料原图；不能生图则给足够详细的文字描述；接网页搜索时只引用来源并标注，不直接侵权粘贴。
- 图文配对审计：图来自哪页、配哪段、是否溢出/遮挡；目标配对率 ≥99%。
- 题目生成后逐题检查：条件完整、答案可验、超纲/无依据即拒。

## 当前 AI 状态（诚实）
- `/api/ask` 目前只吃选中片段，无课程级检索；只在阅读器。
- 逐句证据真实样例 192 段仅 10 段有依据（5.2%），已加 <80% 硬失败。
- 以上两项未达标前，不能宣称“AI 了解资料”或“可挑战顶级 AI”。
