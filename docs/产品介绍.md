# TermFinale 产品介绍

## 引言：为什么做这个

你好，很高兴你愿意试试我做的东西。

我是 Lan，一名普通的大二学生。

每到期末，我们大概都会遇到同样的问题：老师不划重点，没有往届题，只有一本厚厚的教材；给了 PPT，几百页图文混排，翻半天也抓不住重点，不知道从哪看起。好不容易挤出时间想复习，网上的速成课五花八门，又不知道哪个适合自己、听完有没有用。于是反复试错，成绩始终差一点。

我们每个人都有自己的目标，也都有很多想做的事。学校的期末考试，如果只是为了考核和应试，它不该成为限制我们的标准，不该占用我们过多的时间，更不该影响我们的心情，消耗我们做其他事情的心力。

网上找过很多资源，但没有太满意的。所以我一直想做一款自己的工具来解决这件事。很幸运赶上了 AI 全面爆发的时代——有想法，把它落地成现实，并没有想象中那么难。于是我用自己的编程基础，结合 AI 编程工具，前后花了大约大半年，做出了这款产品。

---

## 这个工具适合谁

TermFinale 是一款面向大学生的期末复习工具，目标很直接：**用更少的时间，把一门课复习到能拿分的程度。**

它适合这样的你：

- 期末时间紧，想先抓住重点和考点
- 手里有教材、课件或往年题，但不知道从哪看起
- 希望复习有出处、能对照原书，而不是看一份不知道对不对的总结

它**不适合**这样的你：

- 对专业课很有热情，想逐字吃透每一个知识点
- 目标是刷满绩点，愿意投入大量时间系统学习

如果是后者，这个工具会显得太"应试"，请选择更适合你的方式。

## 关于收费

这个项目会一直免费，不会做成收费软件，也不会有会员制。

但有一个前提需要说清楚：**生成讲义和题目要调用 AI 模型，会产生 token 费用**，这部分是模型厂商收的，不是我收的。

经过初期实测，如果只用免费模型，会出现格式错乱、图文不匹配、图片被吞、胡编乱造等问题——这是免费模型的极限，达不到可用标准。所以项目支持接入几家商用模型，由你自己填 API Key，按量计费，我不经手、不加价。

关于 Key，你不用担心：

- 它只保存在你电脑本机的配置文件里，不会上传到任何地方
- 你随时可以删除或更换
- 如果了解大模型、token、API 这些概念，直接填即可
- 如果不了解，也没关系：按说明注册、拿到 Key、填进去，全程不超过 5 分钟

费用方面，一次生成通常在几分钱到几毛钱；不少平台有新用户赠送额度，以我自己的用量，通常能用很久（具体以平台活动为准）。

## 它和"随便找个 AI 总结"有什么不同

- **每段都有出处**：讲义里的内容标原书页码，能对着教材核对
- **有质量检查**：覆盖页数、引用依据、重复和套话都会被检查，不达标会标出来
- **能打印**：生成的讲义可以直接导出 PDF / Word，按页排版
- **资料留在本机**：课程、笔记、讲义都存在你自己的电脑上

## 目前的局限

由于产品全称都是编者个人独立开发，技术有限，这一版还远不完美，下面这些限制请提前知道：

- **生成的内容仍可能出错**。模型会理解偏差，最终请以原书为准；重要结论建议对照页码核对
- **公式和扫描件是图片**。公式识别可能出错，所以这类页保留原页影像，不强行转文字
- **公式/图片页不能直接出文字题**。需要选择以文字为主的页
- **质量检查是程序 + 模型检查，不是人工逐页复核**。它能把明显问题拦下来，但不能保证 100% 正确
- **扫描件解析慢**。页数多时要等 OCR；可以选择"快速保存"，把识别推迟到第一次生成
- **出卷可能被判定"需重做"**。当答案审计发现冲突时，会整卷退回，不会带着错误交付
- **需要联网和 API Key**。资料、笔记在本机，但生成和问答必须联网
- **只面向期末应试**。不替代系统学习，也不适合想深挖每一个知识点的场景
- **功能仍在完善**。说明页、模板、导出样式等还会继续调整

## V2.0 的想法

下面是一些方向，不代表最终一定做，但会是接下来努力的重点：

- **更完整的本地化**：支持本地模型，减少联网依赖
- **公式能力增强**：公式可搜索、可出题、可校对
- **更聪明的复习路径**：根据错题和掌握度，自动安排每天该看哪几页
- **多设备与备份**：更方便地迁移课程和笔记，支持端到端加密备份
- **讲义模板**：不同的排版风格，适应打印、平板阅读等场景
- **解析提速**：增量解析、缓存和更快的 OCR，减少等待
- **开放与互通**：导入/导出 Anki、Markdown，提供更完整的开放接口
- **质量报告升级**：更清楚地告诉你"哪里可能有问题、为什么"
- **社区平台**：提供在线交流分享服务
- **集成更多复习功能，接入高校题库**

## 技术栈

### 运行环境

- Python 3.14（开发与运行）
- SQLite（本地数据：课程、讲义、错题、笔记、任务）
- macOS 桌面端（pywebview + 系统 WebView），可打包为独立 App

### 后端

- FastAPI + Uvicorn（本地 HTTP 服务）
- Pydantic（数据结构与校验）
- SQLAlchemy（数据库访问）
- OpenAI Python SDK（DeepSeek / Kimi 等兼容接口）
- DashScope SDK（阿里云百炼 / 通义）
- python-multipart（文件上传）
- loguru（日志）
- python-dotenv（本机 Key 配置）
- opencc（简繁转换）
- sympy（公式与数学表达式检查）
- Markdown（文本处理）

### 前端

- 原生 JavaScript（无框架）
- 原生 CSS（自建设计系统与冷色纸感主题）
- KaTeX（公式渲染）
- 自研 Markdown/富文本阅读器、搜索、AI 抽屉

### 文档解析与生成

- PyMuPDF（PDF 解析、页面渲染、合并、裁剪）
- MinerU（扫描件版面分析、OCR、公式区域检测）
- pix2tex（公式图片转 LaTeX）
- Typst（公式排版）
- Playwright（HTML → PDF 渲染）
- python-docx（Word 导出）
- python-pptx（PPT 解析）
- Pillow（图片处理）

### AI 模型

- DeepSeek（生成、对话）
- 阿里云百炼 / Qwen（内容复核、补讲、图片理解）
- Kimi / Moonshot（复核备用）
- 模型均通过用户自己的 API Key 调用

### 桌面与构建

- pywebview（桌面窗口）
- customtkinter（启动画面）
- PyInstaller（打包 macOS App）

### 质量与测试

- 自研质量门禁：结构、内容、PDF、语言、逐页覆盖
- 审计驱动的补讲：发现没讲到的页，自动补讲并重渲染
- unittest 测试集（近 900 项）
- 自建评测集与基准脚本（多份真实教材、页级覆盖与耗时记录）
